字符串处理

C 没有「字符串类型」，字符串就是一个字符数组，最后放一个 '\0' 作结束标志。这一句话想通了，这一环的题和坑就都好理解了：所有循环都是「走到 '\0' 为止」，所有手写的结果都要「最后补一个 '\0'」。

题1逆序输出

代表题 · 2015 第1题（10 分）

从键盘输入一个字符串，再将其逆序输出（如：输入 abcde，输出 edcba）。

要求

print_reverse(s) 把 s 倒着打印出来，最后换行。s 是空串时只打印换行。

对应讲义　②

易错从 len-1 开始；空串时循环一次都不跑。

#include <stdio.h>
#include <string.h>

void print_reverse(char s[])
{
    int i;
    for (i = (int)strlen(s) - 1; i >= 0; i--) printf("%c", s[i]);
    printf("\n");
}

int main(void)
{
    char s[100];
    scanf("%s", s);
    print_reverse(s);
    return 0;
}

输入

abcde

运行结果

edcba

题2回文

变式 · 2012 第5题

输入一字符串，检查是否为回文，若是则输出「回文」，否则输出「非回文」。

回文是指正反序相同的串，如「level」。

要求

is_palindrome(s) 是回文返回 1，不是返回 0（空串和一个字符都算回文）。

  • 思路第 i 个和倒数第 i 个比，只走前一半。

对应讲义　③

易错只比前一半；有一对不同立刻返回 0。

#include <stdio.h>
#include <string.h>

int is_palindrome(char s[])
{
    int len = (int)strlen(s), i;
    for (i = 0; i < len / 2; i++)
        if (s[i] != s[len - 1 - i]) return 0;
    return 1;
}

int main(void)
{
    char s[100];
    scanf("%s", s);
    if (is_palindrome(s)) printf("回文\n");
    else printf("非回文\n");
    return 0;
}

输入

level

运行结果

回文

题3数字串转整数

变式 · 2021 第1题

将字符串转化为十进制数，例如将字符串 "123456" 转换为整数 123456。

要求

str_to_int(s)：s 里全是数字字符（最多 9 位），返回对应的整数。

  • 思路v = v * 10 + (s[i] - '0')。

对应讲义　④

易错减 '0' 才是数值。

#include <stdio.h>

int str_to_int(char s[])
{
    int v = 0, i;
    for (i = 0; s[i] != '\0'; i++) v = v * 10 + (s[i] - '0');
    return v;
}

int main(void)
{
    char s[20];
    int v;
    scanf("%s", s);
    v = str_to_int(s);
    printf("%d\n", v + 1);          /* 加 1 看得出它真是整数了 */
    return 0;
}

输入

123456

运行结果

123457

题4手工连接

综合 · 2024 第3题

设计程序实现两个字符串连接（不能使用字符串连接函数）。

要求

my_strcat(dest, src) 把 src 接到 dest 后面（dest 空间足够）。

不许用 strcat、strcpy、strlen。

  • 思路先让 i 走到 dest 的 '\0'；再把 src 一个个抄到 dest[i]、dest[i+1]…；最后补 '\0'。

对应讲义　⑤

易错两个下标分开；最后补 '\0'。

#include <stdio.h>

void my_strcat(char dest[], char src[])
{
    int i = 0, j = 0;
    while (dest[i] != '\0') i++;
    while (src[j] != '\0') dest[i++] = src[j++];
    dest[i] = '\0';
}

int main(void)
{
    char a[200], b[100];
    scanf("%s%s", a, b);
    my_strcat(a, b);
    printf("%s\n", a);
    return 0;
}

输入

Hello World

运行结果

HelloWorld

题5字符串比较

限时 · 教材第6章习题14 · 限时 15 分钟

编一个程序，将两个字符串 s1 和 s2 比较，若 s1>s2，输出一个正数；若 s1=s2，输出 0；若 s1<s2，输出一个负数。不要用 strcmp 函数。两个字符串由 gets 函数读入。

输出的正数或负数的绝对值应是相比较的两个字符串中相应字符的 ASCII 码的差值。

例如 "A" 与 "C" 相比应输出 -2；"And" 和 "Aid" 比较，根据第 2 个字符比较结果，"n" 比 "i" 大 5，因此应输出 5。

（原题文字写的是「不要用 strcpy」，从题意看应是 strcmp）

要求

my_strcmp(s1, s2) 返回上面说的那个数。

一个串是另一个的前缀时（"ab" 和 "abc"），比到 '\0' 和 'c'，返回 '\0' - 'c' = -99。

对应讲义　⑥

易错循环条件同时判断相等和没到结尾；最后返回差。

#include <stdio.h>

int my_strcmp(char s1[], char s2[])
{
    int i = 0;
    while (s1[i] == s2[i] && s1[i] != '\0') i++;
    return s1[i] - s2[i];
}

int main(void)
{
    char s1[100], s2[100];
    scanf("%s%s", s1, s2);           /* 原题用 gets 读整行，VS 里改用 gets_s 或 scanf */
    printf("%d\n", my_strcmp(s1, s2));
    return 0;
}

输入

And Aid

运行结果

5

编程题怎么写

字符串题的循环条件都是 s[i] != '\0'，不需要知道长度。

通用骨架

for (i = 0; s[i] != '\0'; i++) {    // 走到结束符为止
    处理 s[i];
}
// 写一个新字符串时：i 负责读，k 负责写，最后 t[k] = '\0';

①字符串 = 以 '\0' 结尾的字符数组

char s[] = "cat"; 在内存里是这样：

下标0123
内容'c''a''t''\0'

4 个格子，最后一个是自动加上的 '\0'。所以：

for (i = 0; s[i] != '\0'; i++) ;     // 循环结束时 i 就是长度

循环结束时 i = 3，这就是手写的 strlen。

②逆序输出：从 len − 1 往回打

最后一个字符的下标是 len - 1：

len = strlen(s);
for (i = len - 1; i >= 0; i--) putchar(s[i]);

"abcde" 输出 edcba。从 len 开始就会先打出那个 '\0'。

只是输出的话不用改数组；题目要「把字符串本身倒过来」，才用环06 细8 的「只走一半交换」。

③回文：第 i 个和倒数第 i 个比

第 i 个和第 len - 1 - i 个比，只走前一半，有一对不同就不是：

ok = 1;
for (i = 0; i < len / 2; i++)
    if (s[i] != s[len - 1 - i]) { ok = 0; break; }

"level" 是回文，"abba" 是，"abca" 不是。

空串和只有一个字符的串：循环一次都不跑，ok 保持 1，都算回文。

④数字串转整数：v = v × 10 + 这一位

和环02 ⑤ 的拼数是同一个式子，只是这一位要从字符变成数字（减 '0'）：

is[i]s[i] − '0'v
0'4'44
1'0'040
2'6'6406

忘了减 '0'，写成 v = v * 10 + s[i]，加进去的是 ASCII 码 52、48、54，结果完全不对。

⑤不用库函数连接：先走到末尾，再抄，最后补 '\0'

i = 0;
while (dest[i] != '\0') i++;            // i 停在 dest 的 '\0' 上
for (j = 0; src[j] != '\0'; j++)
    dest[i++] = src[j];
dest[i] = '\0';                          // 最容易漏

"code" 接上 "block" 得 codeblock。dest 至少要 4 + 5 + 1 = 10 格。

常见错：写成 dest[i] = src[i]，两个数组用同一个下标，src 是从它的第 4 个字符开始抄的。所以读和写要两个下标。

⑥手写比较：找第一对不同的字符

两个串一起走，直到某一对不同、或者走到结尾：

i = 0;
while (s1[i] == s2[i] && s1[i] != '\0') i++;
return s1[i] - s2[i];
"And" 和 "Aid"→5 第 2 个不同：'n' − 'i' "A" 和 "C"→-2 "ab" 和 "abc"→-99 走到 '\0' 和 'c' 才不同，短的小

返回值只看正负：正数 s1 大，负数 s1 小，0 相等。

⑦字符分类：字母、数字、空格、其他

if ((c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z')) letter++;
else if (c >= '0' && c <= '9') digit++;
else if (c == ' ') space++;
else other++;

"Hi 2u! A9"：字母 4，数字 2，空格 2，其他 1。

⑧数单词：记住「现在在不在单词里」

用一个标志 in：碰到空格就 in = 0；碰到非空格、而且之前不在单词里，就是新单词开始了：

in = 0; count = 0;
for (i = 0; s[i] != '\0'; i++) {
    if (s[i] == ' ') in = 0;
    else if (in == 0) { in = 1; count++; }
}

"␣␣hi␣␣go␣"（␣ 是空格）有 2 个单词。

数空格再加 1 是错的：开头的空格、结尾的空格、连续的空格都会多算。

细1sizeof 和 strlen 不一样

sizeof 是这个数组占几个字节（含 '\0'，也含没用到的格子）；strlen 是数到 '\0' 之前有几个字符。

char a[] = "0123";→sizeof 5，strlen 4 char b[] = {'0', '1', '2', '3'};→sizeof 4 没有 '\0'，不是字符串 char c[10] = "hi";→sizeof 10，strlen 2 char d[] = "ab\n\\\101";→sizeof 6，strlen 5 转义算 1 个（环02 细4） strlen("ab\0cd")→2 遇到第一个 '\0' 就停

细5四个字符串函数

要 #include <string.h>：

strcpy(a, b)→把 b 连同 '\0' 复制到 a，a 原来的被覆盖 strcat(a, b)→把 b 接到 a 后面 a 要装得下：strlen(a) + strlen(b) + 1 strcmp(a, b)→a 小得负数，相等得 0，a 大得正数 strlen(a)→不含 '\0' 的长度

char a[20] = "ab"; 执行 strcat(a, "xyz") 后 a 是 abxyz，strlen 是 5。

strcmp 的结果只保证正负，不保证是 1 或 −1。判断相等写 if (strcmp(a, b) == 0)。strcmp("A", "a") 是 负数：大写字母的码比小写小（环02 细1）。

strlwr、strupr 不是标准函数；标准的是 <ctype.h> 里的 tolower、toupper，一次改一个字符。

细7字符串常量的长度

转义字符算一个；'\0' 后面的不算：

细8字符和数字互转

'7' - '0'→7 3 + '0'→'3' toupper('q')→'Q' 要 #include <ctype.h> tolower('Q')→'q'

细9多个字符串：二维字符数组 + strcpy

多个名字放在二维字符数组里，一行一个（环07 细9）。排序时比较用 strcmp，交换要用 strcpy 和一个临时数组：

if (strcmp(name[k], name[k + 1]) > 0) {
    strcpy(t, name[k]);
    strcpy(name[k], name[k + 1]);
    strcpy(name[k + 1], t);
}

{"tom", "amy", "bob"} 排完是 amy bob tom。name[0] = name[1]; 不行，一行就是一个数组。

细10装不下、忘补 '\0'：结果都不确定

  • char s[5]; strcpy(s, "hello"); 要 6 格只有 5 格，越界。
  • 手工复制完忘了 t[k] = '\0';，printf 会一直往后打，后面跟一串乱码。

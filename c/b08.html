int age_of(int yend, int mend, int dend, int yman, int mman, int dman)

题5指针字符串链表

选做 · 期末卷 2012-13 的填空题意 + 自编

  • 思路(1) 一样就往后走，但走到哪里必须停？停下以后返回什么？(2) 字符放进 *p 以后，p 要往后挪；读完以后 s 还不是字符串，差什么？(3) 只换主对角线一侧的一半：j 从哪里开始？整个矩阵都换一遍会怎样？(4) p 从头开始，什么时候停，怎么走到下一个结点。

对应讲义　④ ⑥ ⑧

易错① 走到 '\0' 必须停，不然越界；③ 放进去以后 p++；④ 把读进来的 '\n' 换成 '\0'；⑤ j 从 i + 1 开始，从 0 开始会换两遍又换回去。

#include <stdio.h>

int my_strcmp(const char *s1, const char *s2)
{
    int i = 0;
    while (s1[i] == s2[i] && /*①*/ s1[i] != '\0')
        i++;
    return /*②*/ s1[i] - s2[i];
}

void line_echo(void)
{
    char s[81], *p = s;
    while ((*p = getchar()) != '\n')
        /*③*/ p++;
    /*④*/ *p = '\0';
    putchar('[');
    for (p = s; *p != '\0'; p++)
        putchar(*p);
    putchar(']');
}

void transpose3(int a[3][3])
{
    int i, j, t;
    for (i = 0; i < 3; i++)
        for (j = /*⑤*/ i + 1; j < 3; j++) {
            t = a[i][j];
            /*⑥*/ a[i][j] = a[j][i];
            a[j][i] = t;
        }
}

struct item {
    int value;
    struct item *next;
};

int list_sum(const struct item *head)
{
    int s = 0;
    const struct item *p;
    for (p = head; /*⑦*/ p != NULL; /*⑧*/ p = p->next)
        s += p->value;
    return s;
}

开始之前，先回想一下

这些是前面学过、这一环又要用到的基础。想不起来就回到出处那一节再看一眼。

while ((c = getchar()) != '\n') 里的括号 → 赋值外面必须加括号，不然 c 得到的是比较的结果环04 细4

杨辉三角中间的数 → 左上 + 正上环05 ⑥

原地转置，内层 j 从 → i + 1 开始，只换一侧环07 ③

函数把结果交回给调用者靠 → return环09 ②

函数里的 static 局部变量 → 只初始化一次，下次调用接着用环09 细5

打开文本文件来读，方式写 → "r"环13 ②

套路

先通读，再分类填。

填空四步

1  通读：程序要干什么（看题目和注释），输入什么、输出什么
2  认变量：每个变量是干什么的？它后面在哪里被用到？
3  看空的位置：在 if 里 → 填条件；单独一行 → 填语句；在参数里 → 填表达式
4  用一组小数据在纸上走一遍，看输出对不对

看变量后面怎么用是最快的线索：2012 年第 (4) 题后面用了 flag，那 ⑩ 就是判断 flag；2013 年 (1) 的 main 里 printf("%f\n", sum(n))，那 sum 一定要 return s。

①先通读：注释就是答案的一半

原卷的空几乎都带注释：/* x 小于当前最小值 */ 下面的空就是 x < amin；/* 输入学生的成绩 */ 下面的空就是一句 scanf。

  • 空在 if ( )、while ( ) 里：填的是条件，不写分号。
  • 空单独占一行、后面有分号：填的是一条语句，分号已经给了，不要再加。
  • 空在表达式中间（z = z * ____;）：只填缺的那一项。
  • 一个空只填一样东西。答案写得长、要两句才能完成，多半是理解错了。

②循环：读到负数结束——先读一次，循环末尾再读一次

scanf("%f", &x);                // 循环前先读第一个
while (x >= 0) {
    处理 x;
    scanf("%f", &x);            // 循环末尾读下一个：最常考的空
}

少了末尾那句，x 永远不变，死循环。这一类还有「读到 0 结束」「读到 # 结束」，骨架一样。

break 和 continue 的空看后面那句要不要执行：2018-19 (3) 奇数分支 x += 5 以后不能再 x −= 3，所以填 continue；x >= 10 时整个循环停，填 break 的条件 x >= 10。

③条件：区间、闰年、多级判断

  • 区间写成两个比较用 && 连：-1 < x <= 2 要写成 x > -1 && x <= 2。数学写法在 C 里语法能过，但意思是 (-1 < x) <= 2，永远为真。
  • 闰年：(year % 4 == 0 && year % 100 != 0) || year % 400 == 0。
  • 多级 if：前面的分支已经排除掉的情况，后面不用再写。2019-20 (1) 年龄：先比月份，月份相同才比日子：mend < mman 减 1；mend == mman && dend < dman 也减 1。
2026-10-24，生日 2000-10-25→25 岁 月份相同、日子还没到 2026-10-24，生日 2000-10-24→26 岁 今天过生日，不减 2026-10-24，生日 2000-12-01→25 岁 月份还没到
  • 分段函数里「其他情况」：看后面怎么输出。2018-19 (1) 后面写 if (y != -1) … else printf("error")，所以最后的 else 填 y = -1。

④数组：两边是几，中间从哪来

  • 杨辉三角：a[m][0] = a[m][m] = 1;，中间 a[m][n] = a[m-1][n-1] + a[m-1][n];，一行打完 printf("\n")。
  • 原地转置：只换主对角线上方的一半，内层 j = i + 1。j 从 0 开始，每对元素换两次，又换回原样。
  • 3 位数拆位、拼数：百位 i、十位 j、个位 k 拼回去是 i * 100 + j * 10 + k；水仙花的条件是 i*i*i + j*j*j + k*k*k == i*100 + j*10 + k。

⑤函数：return、实参的 &、static

  • 有返回类型的函数，最后一个空常常是 return 结果;。2013 (1) 的 sum 少了 return，main 拿到的是随机值。
  • scanf 的参数是地址：scanf("%d", &n)；数组名、字符数组本身就是地址，不加 &。
  • 「下列程序运行的结果为 k=5、k=12」这类：两次调用结果不同，而函数里有 int c = 3; … c++，说明 c 要保留上次的值——在 int 前面填 static。再用结果反推实参：f(a) = a + c，第一次 c = 3 得 5，所以传 2；第二次 c = 4 得 12，所以传 8。

⑥字符：'\0'、ASCII 运算、循环后移

  • 一个个字符放进数组以后，要补 '\0' 才是字符串：读一行到回车为止，把回车那一格换成 '\0'。
  • 手写 strcmp：一样就往后走，走到 '\0' 必须停；返回两个字符之差 s1[i] - s2[i]。
  • 字母循环后移 5 位：'a'–'u' 直接 c = c + 5；'v'–'z' 要绕回去，'v' + 5 − 26 = 'a'，所以 c = c - 21。通用写法 c = (c - 'a' + 5) % 26 + 'a';。
  • getchar 一次读一个字符，回车也是一个字符。先用 scanf 读了文件名，再用 getchar 读内容时，第一个读到的是文件名后面的回车。

⑦文件：fopen 的方式、按什么读写

fopen(fname, "r")→读，文件必须已经存在 fopen(fname, "w")→写，原来的内容先清空 fscanf(fp, "%d,%d,%d", …)→和 scanf 一样，多一个 fp 格式里的逗号要和文件里的一样 fputc(ch, fp)、fgetc(fp)→一次一个字符

「以 # 结束」：while ((ch = getchar()) != '#') fputc(ch, fp);。fopen 的第一个空是文件名变量 fname，不加引号——加了引号就是打开一个名字叫 fname 的文件。

⑧指针：往后挪、走到头

  • 指针放字符：*p = c 放进去以后 p++；最后 *p = '\0'。
  • 链表遍历：for (p = head; p != NULL; p = p->next)。条件写成 p->next != NULL 会漏掉最后一个结点，空链表还会出错。

考场上

填空的答题习惯。

细1原卷的 void main、gets、印刷错误

原卷是按 Turbo C 年代的写法出的：void main()、main() 不写返回类型、gets(fname)、#include "stdio.h"。照着题意填就行，不用改它的写法。

真有印刷错误时（2013 年杨辉三角第一个 for 印成 for (m = 0; n < N; m++)），在答卷上写一句「此处应为 m < N」，再按正确的意思填。

细2填完用最小的数据走一遍

填完每一空，挑一组最小的输入在纸上走：读到负数结束的，输入 5 -1；闰年用 2000、1900 各试一次；字母后移用 'v'。走不通的那一空就是填错的。

细3网页和 VS 里怎么填

题文件里的 ____（4 条下划线）就是空，把它整个换成你的答案；____p 是要填地址、字符串的空，____f 是要填函数名的空。没填的空一运行到，测试就算这道题「未做」，所以可以一小题一小题地填、一小题一小题地测。

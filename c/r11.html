题1第 K 个字符起复制

代表题 · 2014 第3题（10 分）

请编写一程序，将一字符串的第 K 个字符开始的全部字符复制成为另外一个字符串。

要求：（1）将复制过程单独编写为一个函数，并且采用指针完成；

（2）在主函数中输入字符串和 K 的值，并且在主函数中输出复制结果。

要求

copy_from_k(src, dest, k)：把 src 从第 k 个字符（k 从 1 数）开始的部分复制到 dest。

k < 1 或 k 大于 src 的长度时，dest 变成空串 ""。

用指针游标写（不要用 src[i] 这种下标）。

对应讲义　⑤ ⑥

易错第 k 个是 src+k-1；先判断 k 合法；最后补 '\0'。

#include <stdio.h>

void copy_from_k(char *src, char *dest, int k)
{
    char *p = src;
    int len = 0;
    while (*p != '\0') { len++; p++; }       /* 用指针数长度 */
    if (k < 1 || k > len) { *dest = '\0'; return; }
    p = src + k - 1;
    while (*p != '\0') { *dest = *p; dest++; p++; }
    *dest = '\0';
}

int main(void)
{
    char s[100], t[100];
    int k;
    scanf("%s%d", s, &k);
    copy_from_k(s, t, k);
    printf("%s\n", t);
    return 0;
}

输入

abcdefg 3

运行结果

cdefg

题2自写 strcmp

变式 · 教材第8章习题17

写一函数，实现两个字符串的比较。即自己写一个 strcmp 函数，函数原型为

int strcmp(char *p1, char *p2);

设 p1 指向字符串 s1，p2 指向字符串 s2。要求当 s1=s2 时，返回值为 0；若 s1≠s2，返回它们二者第 1 个不同字符的 ASCII 码差值（如 "BOY" 与 "BAD"，第 2 个字母不同，O 与 A 之差为 79-65=14）。如果 s1>s2，则输出正值；如果 s1<s2，则输出负值。

要求

my_strcmp(p1, p2)（为了不和库函数重名，名字加了 my_）。用指针写，不用下标。

和环08 题5 是同一个算法，这次全部用 *p1、p1++ 来写。

对应讲义　⑤ 环08 ⑥

易错相等且没到结尾才往后走；返回差值。

#include <stdio.h>

int my_strcmp(char *p1, char *p2)
{
    while (*p1 == *p2 && *p1 != '\0') { p1++; p2++; }
    return *p1 - *p2;
}

int main(void)
{
    char s1[100], s2[100];
    scanf("%s%s", s1, s2);
    printf("%d\n", my_strcmp(s1, s2));
    return 0;
}

输入

BOY BAD

运行结果

14

题3指针逆序

变式 · 教材第8章习题14

将 n 个数按输入时顺序的逆序排列，用函数实现。

要求

reverse(a, n) 用两个指针（一个从头、一个从尾）把 a 的前 n 个数原地逆序。

n 为 0 或 1 时什么都不做。

对应讲义　⑦

易错n <= 1 先返回，避免形成 a-1；l < r 时才交换。

#include <stdio.h>

void reverse(int *a, int n)
{
    int *l = a, *r, t;
    if (n <= 1) return;
    r = a + n - 1;
    while (l < r) { t = *l; *l = *r; *r = t; l++; r--; }
}

int main(void)
{
    int a[100], n, i;
    scanf("%d", &n);
    for (i = 0; i < n; i++) scanf("%d", a + i);
    reverse(a, n);
    for (i = 0; i < n; i++) printf("%d ", *(a + i));
    printf("\n");
    return 0;
}

输入

5
1 2 3 4 5

运行结果

5 4 3 2 1

题4找更长的词

综合 · 2017 第5题（20 分）

写一个函数 int find_len_word(char *s1, char *s2)，查找串 s1 中是否包含比指定的词（s2 指向的字符串）长的词，如果存在则返回第 1 次出现的位置，否则返回 -1，约定串中的词由 1 个或 1 个以上的空格符分隔。

要求

find_len_word(s1, s2)：「位置」指那个词第一个字符在 s1 里的下标（从 0 数）。

s1 开头、结尾都可能有空格。

  • 思路一个指针在 s1 上走：跳过空格 → 记下词的起点 → 数这个词的长度 → 和 strlen(s2) 比。

对应讲义　② ⑤ 环08 ⑧

易错跳空格 → 记起点 → 数长度；位置是起点 - s1。

#include <stdio.h>
#include <string.h>

int find_len_word(char *s1, char *s2)
{
    int len2 = (int)strlen(s2), len;
    char *p = s1, *start;
    while (*p != '\0') {
        while (*p == ' ') p++;              /* 跳过空格 */
        if (*p == '\0') break;
        start = p;
        len = 0;
        while (*p != ' ' && *p != '\0') { len++; p++; }
        if (len > len2) return (int)(start - s1);
    }
    return -1;
}

int main(void)
{
    char s1[] = "  I am a student";
    char s2[] = "abc";
    printf("%d\n", find_len_word(s1, s2));   /* student 的 s 在下标 9 */
    return 0;
}

运行结果

9

题5循环移动

限时 · 教材第8章习题4 · 限时 15 分钟

有 n 个整数，使前面各数顺序向后移 m 个位置，最后 m 个数变成最前面 m 个数。

写一函数实现以上功能，在主函数中输入 n 个整数和输出调整后的 n 个数。

要求

move(a, n, m)：把 a 的前 n 个数循环右移 m 位。例如 {1,2,3,4,5} 移 2 位 → {4,5,1,2,3}。

m 可能大于 n（先对 n 取模），也可能是 0。

对应讲义　⑧

易错思路：重复 m 次「最后一个存起来，其余后移一格，放到最前」。m 先对 n 取模。

#include <stdio.h>

void move(int *a, int n, int m)
{
    int k, t, *p;
    if (n <= 0) return;
    m %= n;
    for (k = 0; k < m; k++) {
        t = *(a + n - 1);
        for (p = a + n - 1; p > a; p--) *p = *(p - 1);
        *a = t;
    }
}

int main(void)
{
    int a[100], n, m, i;
    scanf("%d", &n);
    for (i = 0; i < n; i++) scanf("%d", a + i);
    scanf("%d", &m);
    move(a, n, m);
    for (i = 0; i < n; i++) printf("%d ", a[i]);
    printf("\n");
    return 0;
}

输入

5
1 2 3 4 5
2

运行结果

4 5 1 2 3

编程题怎么写

指针版的题，算法和下标版一模一样，只是把 a[i] 换成 *p、把 i++ 换成 p++。

通用骨架

while (*s != '\0') {      // 读游标 s、写游标 t 同步走
    *t = *s;
    s++; t++;
}
*t = '\0';                // 别忘结束符

①先画对象图

int a = 4, *p = &a;：

   a            p
 ┌───┐       ┌────┐
 │ 4 │ ◀──── │ &a │
 └───┘       └────┘

p 里存的是 a 的地址，*p 就是 a。执行 *p = 7; 之后，a 是 7，p 本身没变。

&p 是 p 自己的地址（指针变量也有地址），见细9。

②指针遍历数组：从 a 走到 a + n

for (p = a; p < a + n; p++)
    s += *p;

a + n 是最后一个元素后面那一格（尾后）：可以拿来比较，不能用 * 去读。

int a[4] = {2, 4, 6, 8} 求和得 20，循环结束时 p - a = 4。

再遍历一次，必须先 p = a; 复位，不然 p 从尾后开始，一次都不跑。

③*p++、(*p)++、++*p：先加括号再算

单目运算符从右往左结合，所以 *p++ 是 *(p++)。a = {10, 20, 30}，q = a，依次执行：

v = *q++;→v = 10，q 指向 a[1] 取原来指的值，然后 q 挪 (*q)++;→数组变成 10 21 30 改的是值，q 不动 w = ++*q;→w = 22，数组 10 22 30 先让值加 1，再取

一句话：括号里是谁，谁就变。*(p++) 是 p 变；(*p)++ 是 *p 变。

④子数组：传 a + k

把 a + 2 传给函数，函数里的 p[0] 就是 a[2]。int a[6] = {1, 2, 3, 4, 5, 6}，p = a + 2：p[0] = 3，p[1] = 4，后面还剩 4 个，长度也要跟着减。

⑤指针复制字符串：两个游标同步走

就是骨架那几行。复制完一定补 *t = '\0';（环08 ⑤）。

熟练以后会看到简写：while ((*t++ = *s++) != '\0');，连 '\0' 一起复制了。读得懂就行，自己写用骨架那种更不容易错。

比较两个字符串（题2）也是同步走：while (*p1 == *p2 && *p1 != '\0') { p1++; p2++; }，最后返回 *p1 - *p2。

⑥「第 k 个字符」是 s + k − 1

「第几个」从 1 数，下标从 0 数，差一个。"computer" 从第 4 个字符起是 puter，起点是 s + k - 1；写成 s + k 会得到 uter，少了一个。

还要先检查 k 合不合法：1 ≤ k ≤ 长度。

⑦指针版逆序：两头往中间走

l = a; r = a + n - 1;
while (l < r) {
    t = *l; *l = *r; *r = t;
    l++; r--;
}

l < r 就是环06 细8 的「只走一半」。{1, 2, 3, 4, 5} 逆序后是 5 4 3 2 1。

n = 0 时要先返回，不然 a + n - 1 就是 a - 1，越界。

⑧循环右移 m 位

最后 m 个移到最前面。m 比 n 大时先 m = m % n：右移 8 位和右移 2 位（n = 6）一样。

用辅助数组最直接：第 i 个放到第 (i + m) % n 个位置。{1, 2, 3, 4, 5, 6} 右移 2 位得 5 6 1 2 3 4。

不用辅助数组也行：重复 m 次「把最后一个存起来，其余整体往后挪一格，再把它放到最前面」。往后挪时从右往左，和环06 ⑤ 的插入一样。

指针的各种写法

这一部分的题都是「看写法判断意思」。拿不准就画对象图。

细1定义时的 * 只管紧跟它的名字

int *p, q; 里 p 是指针，q 是普通 int。

int *p = &a; 等于 int *p; p = &a;，不是 *p = &a;：定义时的 * 只是说明 p 是指针。

指针只能存同类型变量的地址；不能直接赋整数（p = 5;），只有 0 或 NULL 可以。

细2数组元素的四种写法

p = a 时，这四个是同一个元素：

a[i]    *(a + i)    p[i]    *(p + i)

&a[i] 和 a + i 是同一个地址。int a[5] = {11, 12, 13, 14, 15}：

*(a + 3)→14 p = &a[1]; 之后 p[2]→14 从 p 开始数 *p + 3→15 先取 *p（12），再加 3 *(p + 3)→15 先挪 3 格，再取

细3数组名不能 ++，指针变量可以

int a[5], *p = a;：p++ 对；a++、a = p 错。数组名是常量地址（回顾里那道）。

函数形参 int a[] 其实是指针变量，所以在函数里 a++ 是可以的。

细4两个指针相减：差几个元素

同一个数组里的两个指针相减，得到的是相隔几个元素，不是字节数：

int a[10]; p1 = a; p2 = &a[5]; p2 - p1→5 double d[10]; q1 = d; q2 = d + 5; q2 - q1→5 也是 5，不是 40

细5字符数组 vs 字符指针

字符数组
char a[] = "cat";
a[0] = 'b';      // 可以：a 有自己的格子
a = "dog";       // 不行：数组名不能赋值
字符指针
char *p = "cat";
p = "dog";       // 可以：改的是指向
p[0] = 'b';      // 不行：改字符串常量

左边执行完 a 是 bat，sizeof(a) 是 4。

两个未定义行为要认得：

  • char *s = "cat"; s[0] = 'b';：改字符串常量，多数环境直接崩溃。
  • char *s; scanf("%s", s);：s 没有指向任何存储。

细6二维数组和行指针

二维数组名 a 是行指针：a + 1 跳过一整行；a[1] + 2 只跳两个元素。

a[i][j]  ==  *(*(a + i) + j)  ==  *(a[i] + j)

int a[3][4] = {{0, 1}, {2, 4}, {5, 8}};：*(*(a + 1) + 1) 是 4，*(a[2] + 1) 是 8。

int (*p)[4] = a; 定义的就是行指针，p 指向「含 4 个 int 的一行」，p[1][1] 也是 4。int *p = a; 类型不对，要写 int *p = a[0]; 或 &a[0][0]。

细7int *p[4] 和 int (*p)[4]：看括号

int *p[4];→指针数组 p 是数组，4 个元素，每个都是 int* int (*p)[4];→数组指针（行指针） p 是一个指针，指向含 4 个 int 的数组

[] 比 * 结合得紧，所以没括号时 p 先和 [4] 结合，是数组；有括号时 p 先和 * 结合，是指针。

指针数组常用来存一组字符串：char *name[3] = {"May", "April", "June"};，name[1] 是 April，name[1][0] 是 'A'。排序时交换指针就行，不用 strcpy。

矩阵综合：按规则填数、压缩存储

矩阵题只有两种难法：按什么顺序走（螺旋、蛇形、旋转），和二维下标怎么换成一维（压缩存储）。前一种先在纸上画 n = 4 的格子，把每一段的起点终点标出来再写循环；后一种只问一个问题：这个元素前面一共有几个数。

题1螺旋填数

必做 · 推测题型

把 1、2、3 …… n×n 按顺时针螺旋的顺序填进 n 阶方阵（从左上角开始向右）。例如 n = 4：

   1  2  3  4
  12 13 14  5
  11 16 15  6
  10  9  8  7

要求

spiral(n, a) 填好 a[0][0] ~ a[n-1][n-1]。1 <= n <= 10。

  • 依据学长清单「矩阵基本变换（加减乘转置、二维转一维、上下三角、连乘、压缩存储、对角矩阵、旋转）」；2018④ 顺时针旋转考的就是下标映射。按规则填数是同一类能力的常见考法（推测）。
  • 思路一圈一圈填。第 k 圈的上边、右边、下边、左边各是哪一段？n 是奇数时最中间只剩一格，别漏也别重复。或者：方向数组 + 「走到边界或已经填过的格子就右转」。

对应讲义　①

易错每条边少走一格，四条边首尾不重叠；n 是奇数时中心单独填。

#include <stdio.h>

void spiral(int n, int a[][10])
{
    int k, i, v = 1;
    for (k = 0; k < n / 2; k++) {                   /* 第 k 圈：左上角 (k, k)，右下角 (n-1-k, n-1-k) */
        for (i = k; i < n - 1 - k; i++) a[k][i] = v++;          /* 上边：向右 */
        for (i = k; i < n - 1 - k; i++) a[i][n - 1 - k] = v++;  /* 右边：向下 */
        for (i = n - 1 - k; i > k; i--) a[n - 1 - k][i] = v++;  /* 下边：向左 */
        for (i = n - 1 - k; i > k; i--) a[i][k] = v++;          /* 左边：向上 */
    }
    if (n % 2 == 1) a[n / 2][n / 2] = v;           /* 中心 */
}

int main(void)
{
    int a[10][10], n, i, j;
    scanf("%d", &n);
    spiral(n, a);
    for (i = 0; i < n; i++) {
        for (j = 0; j < n; j++) printf("%4d", a[i][j]);
        printf("\n");
    }
    return 0;
}

输入

5

运行结果

   1   2   3   4   5
  16  17  18  19   6
  15  24  25  20   7
  14  23  22  21   8
  13  12  11  10   9

题2对称矩阵压缩

必做 · 学长清单

n 阶对称矩阵（a[i][j] == a[j][i]）只存下三角（含对角线）就够了。按行把下三角存进一维数组 b：

b[0] = a[0][0]，b[1] = a[1][0]，b[2] = a[1][1]，b[3] = a[2][0] ……

要求

三个函数（下标都从 0 开始，n <= 10）。

(1) pack_lower(a, n, b)：把 a 的下三角按行存进 b，返回存了几个数。

(2) sym_get(b, n, i, j)：b 是对称矩阵按 (1) 压缩的结果，返回第 i 行第 j 列的元素。

i < j 时它在上三角，没存，要用对称性去取。

(3) sym_mul_vec(b, n, x, y)：只用压缩后的 b，算 y = A × x（A 是 n 阶对称矩阵，x、y 是长 n 的向量）。

  • 依据学长清单「二维转一维、上下三角、压缩存储」；基础环07 只练过输出左下三角。
  • 思路第 i 行前面有 1 + 2 + … + i 个数，所以 a[i][j]（j <= i）在 b 的第几个？(3) y[i] = a[i][0]×x[0] + … + a[i][n-1]×x[n-1]，每个 a[i][j] 用 (2) 取。

对应讲义　② ③

易错a[i][j]（j <= i）在 b 的 i(i+1)/2 + j；i < j 时交换 i、j 再算。

#include <stdio.h>

int pack_lower(int a[][10], int n, int b[])
{
    int i, j, k = 0;
    for (i = 0; i < n; i++)
        for (j = 0; j <= i; j++)
            b[k++] = a[i][j];
    return k;                                       /* n(n+1)/2 */
}

int sym_get(const int b[], int n, int i, int j)
{
    int t;
    if (i < j) { t = i; i = j; j = t; }             /* 上三角：用对称的那个 */
    return b[i * (i + 1) / 2 + j];
}

void sym_mul_vec(const int b[], int n, const int x[], int y[])
{
    int i, j;
    for (i = 0; i < n; i++) {
        y[i] = 0;
        for (j = 0; j < n; j++)
            y[i] += sym_get(b, n, i, j) * x[j];
    }
}

int main(void)
{
    int a[10][10], b[55], x[10], y[10], n, i, j, k;
    scanf("%d", &n);
    for (i = 0; i < n; i++)
        for (j = 0; j < n; j++) scanf("%d", &a[i][j]);
    for (i = 0; i < n; i++) scanf("%d", &x[i]);
    k = pack_lower(a, n, b);
    printf("压缩后 %d 个：", k);
    for (i = 0; i < k; i++) printf("%d ", b[i]);
    printf("\n第 1 行第 3 列（下标 0,2）：%d\n", sym_get(b, n, 0, 2));
    sym_mul_vec(b, n, x, y);
    printf("A × x =");
    for (i = 0; i < n; i++) printf(" %d", y[i]);
    printf("\n");
    return 0;
}

输入

4
4 1 2 0
1 5 3 7
2 3 6 8
0 7 8 9
1 -2 3 1

运行结果

压缩后 10 个：4 1 5 2 3 6 0 7 8 9 
第 1 行第 3 列（下标 0,2）：2
A × x = 8 7 22 19

题3斜向蛇形

必做 · 推测题型

把 1、2、3 …… n×n 沿反对角线（i + j 相同的一条斜线）蛇形填进 n 阶方阵。例如 n = 4：

   1  2  6  7
   3  5  8 13
   4  9 12 14
  10 11 15 16

第 d 条斜线（i + j == d，d 从 0 到 2n-2）：d 是偶数时从左下往右上填（i 从大到小），d 是奇数时从右上往左下填（i 从小到大）。

要求

zigzag(n, a) 填好 a[0][0] ~ a[n-1][n-1]。1 <= n <= 10。

  • 依据川师本科期末卷 2016-17 四-1「利用循环语句按列顺序为 5×5 的二维数组赋值 1 到 25」的升级；学长清单「矩阵基本变换」（推测）。
  • 思路外层枚举斜线 d；这条线上 i 的范围不是 0 ~ d，而是 max(0, d-n+1) ~ min(d, n-1)（后半段的斜线变短了）。

对应讲义　④

易错斜线 d 上 i 的范围是 max(0, d-n+1) ~ min(d, n-1)；奇偶决定走的方向。

#include <stdio.h>

void zigzag(int n, int a[][10])
{
    int d, i, lo, hi, v = 1;
    for (d = 0; d <= 2 * n - 2; d++) {
        lo = d - n + 1 > 0 ? d - n + 1 : 0;
        hi = d < n - 1 ? d : n - 1;
        if (d % 2 == 0)
            for (i = hi; i >= lo; i--) a[i][d - i] = v++;   /* 左下 → 右上 */
        else
            for (i = lo; i <= hi; i++) a[i][d - i] = v++;   /* 右上 → 左下 */
    }
}

int main(void)
{
    int a[10][10], n, i, j;
    scanf("%d", &n);
    zigzag(n, a);
    for (i = 0; i < n; i++) {
        for (j = 0; j < n; j++) printf("%4d", a[i][j]);
        printf("\n");
    }
    return 0;
}

输入

5

运行结果

   1   2   6   7  15
   3   5   8  14  16
   4   9  13  17  22
  10  12  18  21  23
  11  19  20  24  25

题4三对角矩阵

选做 · 学长清单

三对角矩阵只有主对角线和它上下相邻的两条线上有非 0 元素（|i - j| <= 1），其余都是 0。

按行把这些元素存进一维数组 b，例如 n = 4：

  a b 0 0
  c d e 0        b = {a, b, c, d, e, f, g, h, i, j}
  0 f g h
  0 0 i j

要求

两个函数（下标从 0 开始，n <= 10）。

(1) tri_pack(a, n, b)：按行存，返回存了几个数（n = 1 时只有 1 个）。

(2) tri_get(b, n, i, j)：返回原矩阵第 i 行第 j 列的元素；不在三条线上的返回 0。

  • 依据学长清单「对角矩阵」。
  • 思路(2) 先判断 |i - j| <= 1。第 0 行只有 2 个数，后面每行 3 个（最后一行 2 个），a[i][j] 前面一共有几个数？化简以后是一个很短的式子。

对应讲义　⑤

易错a[i][j] 前面有 2 + 3(i-1) + (j-i+1) 个数，化简是 2i + j；不在带上的返回 0。

#include <stdio.h>

int tri_pack(int a[][10], int n, int b[])
{
    int i, j, k = 0;
    for (i = 0; i < n; i++)
        for (j = i - 1; j <= i + 1; j++)
            if (j >= 0 && j < n) b[k++] = a[i][j];
    return k;                                       /* n >= 2 时是 3n - 2 */
}

int tri_get(const int b[], int n, int i, int j)
{
    if (i - j > 1 || j - i > 1) return 0;
    return b[2 * i + j];
}

int main(void)
{
    int a[10][10], b[30], n, i, j, k;
    scanf("%d", &n);
    for (i = 0; i < n; i++)
        for (j = 0; j < n; j++) scanf("%d", &a[i][j]);
    k = tri_pack(a, n, b);
    printf("压缩后 %d 个：", k);
    for (i = 0; i < k; i++) printf("%d ", b[i]);
    printf("\n用压缩数组还原：\n");
    for (i = 0; i < n; i++) {
        for (j = 0; j < n; j++) printf("%4d", tri_get(b, n, i, j));
        printf("\n");
    }
    return 0;
}

开始之前，先回想一下

这些是前面学过、这一环又要用到的基础。想不起来就回到出处那一节再看一眼。

a[i][j] 在主对角线上的条件 → i == j环07 ①

左下三角（含对角线）的条件 → j <= i环07 题2

二维数组作参数，哪一维不能省 → 第二维（列数）环07 细6

4×4 顺时针旋转：新的 b[j][n-1-i] 等于 → a[i][j]环07 题4

1 + 2 + … + i 等于 → i(i+1)/2等差数列求和

套路

先画格子标下标，再写循环。

①螺旋填数：一圈一圈，每条边少走一格

第 k 圈的左上角是 (k, k)，右下角是 (n−1−k, n−1−k)。四条边各走 n−1−2k 格，每条边都不走到头，留给下一条边当起点：

for (i = k; i < n - 1 - k; i++) a[k][i] = v++;          // 上：向右
for (i = k; i < n - 1 - k; i++) a[i][n - 1 - k] = v++;  // 右：向下
for (i = n - 1 - k; i > k; i--) a[n - 1 - k][i] = v++;  // 下：向左
for (i = n - 1 - k; i > k; i--) a[i][k] = v++;          // 左：向上

一共 n / 2 圈；n 是奇数时最中间那格四条边都走不到，要单独填。

另一种写法：方向数组 di[4] = {0, 1, 0, -1}、dj[4] = {1, 0, -1, 0}，下一格出界或已经填过就 d = (d + 1) % 4 右转。写起来短，但要先把数组清 0。

②压缩存储：这个元素前面有几个数

按行存下三角，第 0 行 1 个、第 1 行 2 个……第 i 行前面一共有 1 + 2 + … + i = i(i+1)/2 个数；在本行里它前面还有 j 个。所以

a[i][j]（j <= i）存在 b 的→i(i+1)/2 + j 4 阶，a[3][1]→b[7] 6 + 1 n 阶一共存→n(n+1)/2 个

所有压缩存储题都是这一句话：数前面有几个。按列存、存上三角、下标从 1 开始，都不用背公式，现场数一遍。

③上三角没存：交换 i、j

对称矩阵 a[i][j] == a[j][i]。i < j 时 (i, j) 在上三角，没存；它等于 (j, i)，而 (j, i) 在下三角。所以先 交换 i 和 j 再套 ② 的公式。

用压缩数组做运算（矩阵乘向量、两个对称矩阵相加）时，不要还原成二维再算，每次用取元素的函数去取——这正是题目想考的。

④斜向蛇形：外层是斜线，内层是斜线上的格子

同一条反对角线上 i + j 相同。设 d = i + j，d 从 0 到 2n − 2。

第 d 条线上 i 的范围：

d <= n − 1（前半）→i 从 0 到 d d > n − 1（后半）→i 从 d − n + 1 到 n − 1 不然 j = d − i 会超过 n − 1 合起来→max(0, d−n+1) ～ min(d, n−1)

n = 4 时第 5 条线（d = 5）上有 2 个格子：(2,3)、(3,2)。

方向只看 d 的奇偶：i 从大到小走是「往右上」，从小到大是「往左下」。

期末卷里的同类

利用循环语句按列顺序为 5×5 的数组 A 赋值 1 到 25，计算两条对角线上的元素之和，并输出左下三角 → 按列：外层 j、内层 i；两条对角线 i == j 和 i + j == n - 1，n 是奇数时中心只能加一次川师卷2016-17 四-1

⑤对角矩阵：带状压缩

三对角矩阵：|i − j| <= 1 以外全是 0。按行存，第 0 行 2 个，中间每行 3 个，最后一行 2 个，共 3n − 2 个（n >= 2）。

a[i][j] 前面有几个：前 i 行是 2 + 3(i − 1)，本行它前面还有 j − (i − 1) 个，合起来化简是 2i + j。

n = 4，a[2][3]→b[7] 2×2 + 3 n = 4，a[0][0]→b[0]

取元素时先判断在不在带上，不在直接返回 0，否则公式会算出一个看起来合法的下标，取到别的元素。

易错清单

写完对照一遍。

细1先画 n = 4，再验 n = 1、2、奇数

n = 1、n = 2 和奇数阶最容易出错：螺旋的 n = 1 一圈都不走（n / 2 是 0），只靠「单独填中心」那一句；n = 2 只有一圈且没有中心。写完用 n = 1、2、3 心算一遍。

细2二维数组参数：int a[][10]

函数参数写 int a[][10]，列数必须是常量。实际只用前 n 行 n 列，n <= 10。int a[][n] 在考试按错误处理（变长数组，VS 不支持）。

细3题目下标从 1 开始时

教材和数据结构书上的公式常是下标从 1 开始：a[i][j] 存在 b[i(i−1)/2 + j − 1]（b 也从 0 开始时）。别背，用 ② 的方法现场数：第 i 行前面有 1 + … + (i − 1) 个。

题1鸡兔同笼

代表题 · 2019 第2题

鸡兔同笼：已知笼里共有 35 个头，94 条腿，请设计程序计算出该笼里鸡、兔分别有多少只。

要求

chicken_rabbit(heads, legs) 打印「鸡的只数 兔的只数」再换行，比如 "23 12\n"；如果没有合理的解（只数不能是负数或小数），打印 "无解\n"。

  • 思路枚举鸡的只数 x 从 0 到 heads，兔 = heads - x，检查腿数对不对。（也可以直接解方程，但要自己判断有没有解——枚举法更稳）

对应讲义　⑦

易错没找到时要打印无解——用标志变量记有没有找到。

#include <stdio.h>

void chicken_rabbit(int heads, int legs)
{
    int x, found = 0;
    for (x = 0; x <= heads; x++) {
        if (2 * x + 4 * (heads - x) == legs) {
            printf("%d %d\n", x, heads - x);
            found = 1;
        }
    }
    if (!found) printf("无解\n");
}

int main(void)
{
    chicken_rabbit(35, 94);      /* 打印：鸡 兔 */
    return 0;
}

运行结果

23 12

题2兑换方案

变式 · 2018 第1题

编写程序实现输出 100 元人民币兑换成 1 元、2 元、5 元的所有兑换方案。

提示：1*x+2*y+5*z=100，其中 x、y、z 为非负整数。

要求

exchange(total) 把 total 元的所有兑换方案打印出来，每行一种："x y z\n"（1 元张数 2 元张数 5 元张数）；最后一行打印方案总数，比如 "10\n"。

顺序规定：外层 5 元张数 z 从 0 往上，内层 2 元张数 y 从 0 往上。

  • 思路两层循环（z、y），x 由 total - 5z - 2y 算出来，不再枚举。

对应讲义　① ② ⑤

易错y 的上界随 z 变；x 算出来不用枚举；count 在循环外清零。

#include <stdio.h>

void exchange(int total)
{
    int y, z, count = 0;
    for (z = 0; z <= total / 5; z++)
        for (y = 0; y <= (total - 5 * z) / 2; y++) {
            printf("%d %d %d\n", total - 5 * z - 2 * y, y, z);
            count++;
        }
    printf("%d\n", count);
}

int main(void)
{
    exchange(100);
    return 0;
}

题3组合个数

变式 · 2016 第5题

写一个程序，求出用 1、2、5 这三个数不同个数组合的和为 100 的组合个数。

要求

count_ways(total) 返回用 1、2、5 组合成 total 的组合个数（每个数可以用 0 个）。

  • 思路和题2 是同一个模型，只计数不输出。要求只用两层循环。

对应讲义　② ③

易错z、y 确定后 x 唯一且一定 >= 0，所以每组 (z, y) 就是一种。

#include <stdio.h>

int count_ways(int total)
{
    int y, z, count = 0;
    for (z = 0; z <= total / 5; z++)
        for (y = 0; y <= (total - 5 * z) / 2; y++)
            count++;
    return count;
}

int main(void)
{
    printf("%d\n", count_ways(100));
    return 0;
}

运行结果

541

题4乒乓球配对

综合 · 教材第5章习题17

两个乒乓球队进行比赛，各出 3 人。甲队为 A、B、C 3 人，乙队为 X、Y、Z 3 人。

已抽签决定比赛名单。有人向队员打听比赛的名单，A 说他不和 X 比，C 说他不和 X、Z 比，请编程序找出 3 对赛手的名单。

要求

print_pairs() 打印所有满足条件的名单，每种一行，格式 "A--? B--? C--?\n"。

  • 思路用三个 char 变量表示 A、B、C 的对手，各从 'X' 枚举到 'Z'；条件 = 三人对手互不相同 + A 不对 X + C 不对 X 也不对 Z。

对应讲义　⑥

易错三人的对手要互不相同；字符可以直接 ++ 和比较。

#include <stdio.h>

void print_pairs(void)
{
    char a, b, c;
    for (a = 'X'; a <= 'Z'; a++)
        for (b = 'X'; b <= 'Z'; b++)
            for (c = 'X'; c <= 'Z'; c++)
                if (a != b && a != c && b != c && a != 'X' && c != 'X' && c != 'Z')
                    printf("A--%c B--%c C--%c\n", a, b, c);
}

int main(void)
{
    print_pairs();
    return 0;
}

运行结果

A--Z B--X C--Y

题5百钱百鸡

限时 · 自编（G4-1，代替原来要求用指针的题） · 限时 15 分钟

公鸡 5 元一只，母鸡 3 元一只，小鸡 1 元三只。用 100 元恰好买 100 只鸡（某种鸡可以一只不买），编程输出所有买法（公鸡、母鸡、小鸡各几只），最后输出共有几种买法。

要求

hundred_chickens() 每种买法打印一行 "公鸡 母鸡 小鸡\n"（三个数用空格隔开），按公鸡从少到多、再按母鸡从少到多的顺序；最后一行打印买法总数。

  • 先写出范围再动手公鸡最多几只？母鸡最多几只？小鸡为什么不用枚举？

对应讲义　④

易错范围：公鸡 <= 20，母鸡 <= 33；小鸡 = 100 - 公鸡 - 母鸡。卡点：先判 z % 3 == 0。

#include <stdio.h>

void hundred_chickens(void)
{
    int x, y, z, count = 0;
    for (x = 0; x <= 20; x++)
        for (y = 0; y <= 33; y++) {
            z = 100 - x - y;
            if (z >= 0 && z % 3 == 0 && 5 * x + 3 * y + z / 3 == 100) {
                printf("%d %d %d\n", x, y, z);
                count++;
            }
        }
    printf("%d\n", count);
}

int main(void)
{
    hundred_chickens();
    return 0;
}

编程题怎么写

枚举就是「全部试一遍」。写之前先回答：每个变量最小是几、最大是几？

通用骨架

count = 0;
for (x = 0; x <= X的上限; x++)
    for (y = 0; y <= Y的上限; y++) {
        z = 由条件算出来;            // 能算出来的变量不再枚举
        if (z 合法 && 其他条件) { count++; 输出这一组; }
    }

①先定每个变量的范围

范围用「全花在这一种上，最多几个」来定。100 元换 1、2、5 元：5 元最多 20 张，2 元最多 50 张，1 元最多 100 张。

范围要带端点：z 从 0 到 20，写 z <= 20。一张 5 元都不要，也是一种方案。

②能算出来的变量，不再枚举

x + 2y + 5z = 100，z 和 y 定了，x 就是 100 − 5z − 2y，不用再试。

三层：x、y、z 都试
for (z = 0; z <= 20; z++)
  for (y = 0; y <= 50; y++)
    for (x = 0; x <= 100; x++)
      if (x + 2*y + 5*z == 100)
        count++;
两层：x 算出来
for (z = 0; z <= 20; z++)
  for (y = 0; y <= (100 - 5*z) / 2; y++)
    count++;    // x = 100-5z-2y，一定 >= 0

两种都得 541 种方案。左边判断了 108171 次，右边只循环 541 次。题3 要求「只用两层循环」，就是这个意思。

③计数器在所有循环外面清零

count = 0 写在最外层循环前面。写进循环里面，每一轮都被清零，最后只剩 0 或 1。

反过来，每一组方案自己用的临时量（比如算出来的 z），在循环里面算。

④整除陷阱：先判断能不能整除

百钱百鸡：公鸡 5 元、母鸡 3 元、小鸡 1 元 3 只，100 元买 100 只。小鸡 z 只花 z / 3 元，可 z / 3 是整除（环01 ①）：z = 4 时 4 / 3 = 1，相当于 4 只小鸡只花了 1 元。

z = 100 - x - y;
if (z % 3 == 0 && 5*x + 3*y + z/3 == 100) …    // 先判 z 能被 3 整除

判了 z % 3 == 0 得 4 种（对）；没判得 7 种，多出来的是小鸡「买了零头」。

⑤每一组都输出，最后输出总数

count++ 和 printf 放在同一个 if 里，一组一行，循环结束后再打印总数。拿 10 元换 1、2、5 元试一下（外层 z、内层 y，每行 x y z）：

for (z = 0; z <= 10 / 5; z++)
    for (y = 0; y <= (10 - 5*z) / 2; y++) {
        x = 10 - 5*z - 2*y;
        printf("%d %d %d\n", x, y, z);
        count++;
    }
printf("%d\n", count);

前两行是 10 0 0 和 8 1 0，一共 10 种。题2 规定的顺序就是外层 z、内层 y。

⑥逻辑配对：把对手当成字符来枚举

甲队 A、B、C 对乙队 X、Y、Z。用三个 char 变量 a、b、c 表示 A、B、C 各自的对手，每个从 'X' 枚举到 'Z'：

for (a = 'X'; a <= 'Z'; a++)
  for (b = 'X'; b <= 'Z'; b++)
    for (c = 'X'; c <= 'Z'; c++)
      if (a != b && b != c && a != c       // 三个对手互不相同
          && 题目给的条件)
        printf("A--%c B--%c C--%c\n", a, b, c);

字符能 ++、能比大小，因为它就是整数（环02 细1）。题目条件「A 说他不和 X 比，C 说他不和 X、Z 比」写成 a != 'X' && c != 'X' && c != 'Z'，结果是 A--Z B--X C--Y。

⑦能解方程就解，不能就枚举

鸡兔同笼 35 头 94 腿，解方程：兔 = (94 − 2×35) / 2 = 12，鸡 = 23。

枚举也行：鸡 x 从 0 试到 35，兔就是 35 − x，检查 2*x + 4*(35 - x) == 94。枚举的好处是无解的情况自动处理：腿数是奇数、或者腿比头的 2 倍还少，一个都试不出来，打印「无解」就行。

⑧估一下要循环多少次

两层各 100 次就是 1 万次，三层就是 100 万次，计算机一眨眼就跑完。考试不用担心快慢，但题目说「尽量减少循环层数」时，要写成 ② 那样。

细6穿透：没有 break 就一直往下走

匹配到一个 case 以后，一直往下执行，直到遇到 break 或者 switch 结束，下面的 case 标签拦不住它。

switch (n) {
    case 1: printf("one ");
    case 2: printf("two ");
    case 3: printf("three "); break;
    default: printf("other ");
}

n = 1 输出 one two three，n = 2 输出 two three，n = 4 输出 other。

default 写在哪都行，只有一个 case 都没匹配上时才进去，进去以后同样会往下穿透：

s = 0;
for (n = 0; n < 4; n++)
    switch (n) {
        default: s += 4;
        case 1: s += 1; break;
        case 2: s += 2; break;
        case 3: s += 3;
    }

s = 11：n = 0 走 default，加 4 再穿透加 1；n = 1、2、3 各加 1、2、3。

多个 case 共用一段：case 1: case 3: case 5: printf("奇数"); break;。成绩分档常写 switch (score / 10)。

细7循环里的 switch：break 归 switch，continue 归循环

break 只跳出 switch，循环照样继续；continue 不属于 switch，它直接作用于外面的循环。

i = 1; k = 0;
for (; i < 6;) {
    switch (i % 3) {
        case 0: k++;
        case 1: k++; break;      // 跳出 switch，接着执行 i += 1
        case 2: k++; continue;   // 跳过 i += 1，直接下一轮
    }
    i += 1;
}

i = 1 正常走完变成 2。i = 2 时进 case 2，continue 跳过了 i += 1，i 永远是 2，这是个 死循环。

细9三种循环可以互相改写

for (i = 1; i <= 10; i++) s += i;

do-while 至少做一次，所以只有条件第一次就成立时，它才和另外两种完全等价。

题1水仙花数

代表题 · 2016 第1题

编程找出所有的"水仙花数"。水仙花数是一个三位正整数，其各位数字立方和等于该数本身。例如 153 = 1³ + 5³ + 3³。

要求

is_narcissus(x) 判断一个三位数 x 是不是水仙花数，是返回 1，不是返回 0。

  • 考试时 main 里写for (x = 100; x <= 999; x++) if (is_narcissus(x)) printf("%d\n", x);

对应讲义　②

易错十位是 x/10%10；比较的是立方和与原数。

#include <stdio.h>

int is_narcissus(int x)
{
    int a = x / 100, b = x / 10 % 10, c = x % 10;
    return a * a * a + b * b * b + c * c * c == x;
}

int main(void)
{
    int x;
    for (x = 100; x <= 999; x++)
        if (is_narcissus(x)) printf("%d\n", x);
    return 0;
}

运行结果

153
370
371
407

题2除 11 等于平方和

变式 · 2014 第1题

求所有满足下列条件的三位数：它除以 11 等于它各位数字的平方和。

例如 550 除以 11 商 50，而 5²+5²+0² = 50。

要求

check(x) 判断三位数 x 是否满足条件，是返回 1，不是返回 0。

  • 注意"除以 11 等于"要能整除。121/11 = 11，但 1+4+1 = 6，不满足。

对应讲义　②

易错先判断能被 11 整除，再比商和平方和。

#include <stdio.h>

int check(int x)
{
    int a = x / 100, b = x / 10 % 10, c = x % 10;
    return x % 11 == 0 && x / 11 == a * a + b * b + c * c;
}

int main(void)
{
    int x;
    for (x = 100; x <= 999; x++)
        if (check(x)) printf("%d\n", x);
    return 0;
}

运行结果

550
803

题3十进制转二进制

变式 · 2019 第1题

输入一个十进制正整数，转换为对应的二进制数并输出。

要求

to_binary(n, out) 把 n 的二进制写成字符串放进 out。

例如 n=6 时 out 变成 "110"。n=0 时写 "0"。

对应讲义　④ ⑦

易错n=0 单独处理；余数要倒序放；最后补 '\0'。

#include <stdio.h>

void to_binary(int n, char out[])
{
    int bits[32], len = 0, i;
    if (n == 0) { out[0] = '0'; out[1] = '\0'; return; }
    while (n > 0) {
        bits[len++] = n % 2;
        n /= 2;
    }
    for (i = 0; i < len; i++)
        out[i] = (char)('0' + bits[len - 1 - i]);
    out[len] = '\0';
}

int main(void)
{
    int n;
    char out[40];
    scanf("%d", &n);
    to_binary(n, out);
    printf("%s\n", out);
    return 0;
}

输入

13

运行结果

1101

题4同构数

综合 · 2015 第4题

找出 1 至 99 之间的全部同构数。同构数出现在它平方数的右边，如 5 是 25 右边的数，25 是 625 右边的数，5 和 25 都是同构数。

要求

is_automorphic(x) 判断 x（1~99）是不是同构数，是返回 1，不是返回 0。

  • 关键先数出 x 有几位，再决定平方数取末几位。

对应讲义　③ ⑥

易错先复制 x 再数位数；10 的幂用整数乘。

#include <stdio.h>

int is_automorphic(int x)
{
    int m = x, mod = 1;
    while (m > 0) {
        mod *= 10;
        m /= 10;
    }
    return x * x % mod == x;
}

int main(void)
{
    int x;
    for (x = 1; x <= 99; x++)
        if (is_automorphic(x)) printf("%d ", x);
    printf("\n");
    return 0;
}

运行结果

1 5 6 25 76

题5数字 1 的个数

综合 · 2022 第1题

输入一个正整数 n，统计 1 到 n 的所有数中"1"出现的次数，并输出。

要求

count_one(n) 返回次数。11 里有两个 1，要算 2 次。

对应讲义　⑧

易错每个 i 都要重新复制到 t 再拆；一个数里可能有多个 1。

#include <stdio.h>

int count_one(int n)
{
    int i, t, count = 0;
    for (i = 1; i <= n; i++) {
        t = i;
        while (t > 0) {
            if (t % 10 == 1) count++;
            t /= 10;
        }
    }
    return count;
}

int main(void)
{
    int n;
    scanf("%d", &n);
    printf("%d\n", count_one(n));
    return 0;
}

输入

13

运行结果

6

编程题怎么写

拆位只有两个动作：% 10 取出个位，/ 10 去掉个位。

通用骨架

int m = n;                 // 先复制一份，n 后面还要用
while (m > 0) {
    d = m % 10;            // 取个位
    // 用 d：计数、求和、判断，或者拼数 r = r * 10 + d
    m /= 10;               // 去个位
}

①拆位：% 10 取个位，/ 10 去个位

拆 472，每轮先取个位、再去个位：

mm % 10m / 10
472247
4774
440

m 变成 0，循环结束。注意数字是从个位往高位出来的：2、7、4。要按原来的顺序用，就得先存起来再倒着用（见 ⑦）。

②三位数可以直接拆

位数固定时不用循环，一句一位。x = 153：

x / 100百位1 x / 10 % 10十位5 先去掉个位，再取个位 x % 10个位3 x % 10 / 10→0 顺序反了：个位 3 再除以 10 就没了

水仙花数就是判断 百位³ + 十位³ + 个位³ 是不是等于 x 本身。立方写 d * d * d，不要用 pow（见细10）。

③先复制一份再拆

拆位循环会把 m 一直除到 0。如果后面还要用原来的数（比如数完位数再去比较），一开始就要复制：

int m = n, cnt = 0;
while (m > 0) { cnt++; m /= 10; }
// 循环结束：m 是 0，n 还是原来的数

n = 25 时，cnt = 2，循环结束后 m = 0，n = 25。

④n 是 0 的时候

while (m > 0) 遇到 m = 0，一次都不进去。所以用上面的写法数 0 的位数，得 0，可 0 明明是 1 位数。

「0 有几位」「0 的二进制」这种情况要单独处理，或者改用 do { … } while (m > 0);，先做一次再判断。

⑤拼数：r = r * 10 + d

从个位往外取，同时往 r 后面接，数就倒过来了：

r = 0;
while (m > 0) { r = r * 10 + m % 10; m /= 10; }

1230 倒过来拼成 321：末尾的 0 跑到最前面，就没了。

环08 的「数字串转整数」用的是同一个式子：v = v * 10 + (s[i] - '0')。

⑥取末 k 位：用整数乘出 10 的 k 次方

同构数要比较「x 的平方的末几位」和 x。x 是两位数就要 % 100，一位数就 % 10。这个 100 用整数一路乘出来：

int mod = 1, t = x;
while (t > 0) { mod *= 10; t /= 10; }   // x 有几位，mod 就乘几次 10
if (x * x % mod == x) …

x = 25 时 mod = 100，625 % 100 = 25，所以 25 是同构数。

625 % pow(10, 2) 编译不过：pow 返回的是 double，% 两边必须是整数。

⑦十转二：除 2 取余，倒着输出

和 ① 一模一样，只是把 10 换成 2。6 依次得到的余数是 0 1 1，倒过来 110 才是二进制。

所以余数要先存进数组，最后从后往前用。题3 要你把结果写成字符串，还有两个细节：

  • 数字 d 变成字符要写 '0' + d：'0' + 1 是字符 '1'（细2）。
  • 字符串最后一定补 '\0'，否则 printf 不知道在哪里停。测试会查这个。

⑧外层换一个数，内层要重新复制

统计 1 到 n 里数字 1 出现几次，外层枚举每个数，内层拆位：

for (i = 1; i <= n; i++) {
    int t = i;              // 每换一个数都重新复制
    while (t > 0) { if (t % 10 == 1) total++; t /= 10; }
}

1 到 12：1、10、11、12 里一共有 5 个 1（11 算两个）。

如果直接拿 i 去拆，i /= 10 会把外层的循环变量改掉，循环就乱了。

细1字符就是一个小整数

char c = 'A'; 存进去的其实是 65（A 的 ASCII 码）。用 %c 打出来是 A，用 %d 打出来是 65。

三个码要背：'A' 是 65，'a' 是 97（小写比大写大 32），'0' 是 48。

'0'、0、'\0' 是三样东西：数字字符 0（值 48）、整数 0、空字符（值是 0，是字符串的结束标志）。所以 '\0' == 0 为真，'0' == 0 为假。

char c = 'A' + 2; 用 %c→C 同一个 c 用 %d→67

细9负数拆位

回忆环01 细5：负数的 / 和 % 都往 0 的方向。-472 % 10 是 -2，-472 / 10 是 -47。

所以 while (m > 0) 遇到负数一次都不跑。题目没说一定是正数时，先 if (m < 0) m = -m; 再拆。

细10用 pow 要小心

pow(5, 3) 返回的是 double 125.0，不是 int。所以：

  • x % pow(10, 2) 编译不过（% 两边要整数）。
  • 用它判断整数相等也不稳：小数在计算机里可能有误差。

拆位求立方和，写 d * d * d 最稳。

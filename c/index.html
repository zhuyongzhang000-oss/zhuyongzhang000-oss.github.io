C 语言讲义

按考研编程题的题型分成 13 个环。每一环前半讲编程题怎么写，后半讲选择题、读程序题爱考的细节；开头的「开始之前」会把前面学过、这一环又要用的基础再考你一遍。

目录

13 个环

  1. 01级数与数学模拟

    求和、求积、递推、精度循环、第几天。细节：变量名、八进制、整除取余、类型转换、i++、逗号、printf/scanf、程序结构、算法特性。

  2. 02数位处理

    拆位、拼数、十转二。细节：字符就是整数、ASCII、转义字符、"a" 和 'a'、%c 读到空格回车、%o %x、位运算。

  3. 03素数与因子

    判素数、完数、最大公约数、筛法。细节：关系和逻辑运算只得 0 或 1、短路、优先级、if (x = 0)、else 配对、?:、循环跑几次、break/continue。

  4. 04枚举与组合

    鸡兔同笼、钱币兑换、配对、百钱百鸡。细节：for 的省略写法、嵌套循环次数、条件里带 ++、读字符的循环、switch 合法写法、穿透、死循环。

  5. 05图案输出

    三角形、菱形、错位星号、杨辉三角。细节：putchar 和 puts、宽度对齐、每行 k 个换行、内外层用了同一个变量、字母图案。

  6. 06排序·查找·插入·合并

    冒泡、选择、二分、插入、合并、奇偶分组。细节：数组长度必须是常量、初始化补 0、下标 0 到 n−1、数组名不能赋值、sizeof、数组作参数。

  7. 07矩阵操作

    转置、左下三角、局部极大、旋转、矩阵连乘、鞍点。细节：二维数组初始化、只能省行数、按行存储、a[i] 是一行、作参数时列数必须写。

  8. 08字符串处理

    逆序、回文、转整数、连接、比较。细节：'\0'、sizeof 和 strlen、字符数组不能用 = 赋值、%s 读到空格停、strcpy/strcat/strcmp/strlen、== 比的是地址。

  9. 09函数与指针参数

    写函数、指针交换、maxmin、插入函数、矩阵函数。细节：不能嵌套定义、先声明后调用、作用域、static 局部变量、auto/register/extern、& 和 *、*n++。

  10. 10递归

    猴子吃桃、整数转字符串、递归改错、勒让德多项式、拉丁方阵。细节：#define 原样替换、宏要加括号、宏参数里的 ++、#include 两种写法、条件编译。

  11. 11用指针处理数组和字符串

    第 k 个字符起复制、指针版 strcmp、逆序、找单词、循环右移。细节：a[i] 和 *(a+i)、数组名不能 ++、指针相减、char 数组和 char 指针、int *p[4] 和 int (*p)[4]、函数指针、二级指针、malloc。

  12. 12结构体与链表

    学生成绩表、日期第几天、打印记录、按分数排序、链表删除结点。细节：} 后的分号、三种定义方式、. 和 ->、整体赋值、union、enum、typedef。

  13. 13文件

    转大写存文件、多行写入再读出、学生成绩写文件、两个文件合并排序、文件排序。细节：FILE *、r/w/a、EOF 是 −1、feof 多读一次、fgets 带回车、fclose。

拔高

基础 13 环全部做完再开始。题少而精：每个专题 3 道必做 + 1 道选做，专门练难点和单考可能的新考法；最后一个是读程序难点集。为什么选这些专题，见 拔高/考情分析.md。

  1. 拔01字符串进阶

    子串定位与替换、单词逆序、同数异形体、奇偶交替重构。套路：暴力匹配回退、读写游标、分词三步、cnt[10] 计数。

  2. 拔02矩阵综合

    螺旋填数、对称矩阵压缩、斜向蛇形、三对角矩阵。套路：按圈分四条边、按斜线枚举、数「前面有几个」得下标公式。

  3. 拔03递归回溯

    有重复的全排列、选 k 个凑和、补全拉丁方阵、凑钱方案数。套路：used[] 排列、start 组合、格子编号、f(剩下, 第 i 种)。

  4. 拔04指针与函数接口

    最大次大和次数、字符串指针数组、函数指针排序、行指针最大行。套路：结果靠指针、返回值报状态；交换指针不搬串；before(x, y) 规则；int (*a)[4]。

  5. 拔05链表

    建表和有序插入、逆置和删除、有序合并去重、约瑟夫环。套路：改 head 的情况单独处理、p 停在前一个、三指针逆置、哨兵结点、循环链表 pre 走 m−1 步。

  6. 拔06数学精度

    大数阶乘、标准差、二分法和牛顿迭代、分数精确求和。套路：数组逐位乘进位、两遍扫描、精度控制循环、先约分再相乘。

  7. 拔07读程序难点

    32 道猜输出和判断，多数是川师期末卷的读程序、选择题原题。方法：追踪表、画递归栈、static 只初始化一次、先加括号再算、宏先展开。

怎么用

  • 读讲义：下划线是留给你的空，先自己想，再点开对答案。右上角「全部揭开」可以一次看全部。
  • 做自测：VS 里打开这一环的 自测.c，启动项 ringNN_quiz，凭记忆做，不要回来翻。
  • 写题1–题5：启动项 ringNN_test，一次测 5 道。卡住先看题文件头写的「讲义 第几节」。
  • 测一下：都过了，在 C 对话里说「测 环NN」，做题库里的小题。错题进回访。

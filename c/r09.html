题1梯形面积

代表题 · 2017 第2题

编写函数求梯形面积；编写主函数从键盘输入梯形的上底、下底和高的值，调用上述函数输出梯形面积（保留小数点后两位）。

要求

trapezoid_area(top, bottom, h) 返回梯形面积 (上底+下底)*高/2。

  • 考试时还要写 mainscanf("%lf%lf%lf", …) 读入，printf("%.2f\n", …) 输出。

对应讲义　① ②

易错参数都是 double，/2 不会整除。

#include <stdio.h>

double trapezoid_area(double top, double bottom, double h)
{
    return (top + bottom) * h / 2;
}

int main(void)
{
    double top, bottom, h;
    scanf("%lf%lf%lf", &top, &bottom, &h);
    printf("%.2f\n", trapezoid_area(top, bottom, h));
    return 0;
}

输入

3 5 4

运行结果

16.00

题2指针交换

变式 · 2017 第1题（10 分）

在主函数中定义 2 个双精度变量 x, y，并输入值，编写一个函数实现交换变量 x, y 的值，要求函数的参数是指针类型，并编写一个主函数进行调用。

要求

swap(a, b) 交换 a、b 指向的两个 double。

  • 考试时 main 里scanf("%lf%lf", &x, &y); swap(&x, &y); printf(…);
  • 注意中间变量是 double t，不是 double *t。

对应讲义　④ ⑤

易错中间变量是 double，不是指针；交换的是 *a 和 *b。

#include <stdio.h>

void swap(double *a, double *b)
{
    double t = *a;
    *a = *b;
    *b = t;
}

int main(void)
{
    double x, y;
    scanf("%lf%lf", &x, &y);
    swap(&x, &y);
    printf("x = %.2f, y = %.2f\n", x, y);
    return 0;
}

输入

1.5 2.5

运行结果

x = 2.50, y = 1.50

题3最大最小

变式 · 2013 第3题（15 分）

用指针作函数参数，编程求一维数组中的最大和最小的元素值。已将主函数和 maxmin() 的原型给出，要求编写求最大最小值函数 maxmin() 的定义实现部分。

#define N 10
main()
{
    void maxmin(int arr[], int *pt1, int *pt2, int n);
    int array[N] = {10,7,19,29,4,0,7,35,-16,21}, *p1, *p2, a, b;
    p1 = &a;  p2 = &b;
    maxmin(array, p1, p2, N);
    printf("max=%d,min=%d", a, b);
}

要求

maxmin 的函数体：最大值放进 *pt1，最小值放进 *pt2。

  • 注意最大最小的初值用 arr[0]，不要用 0（全是负数时就错了）。

对应讲义　⑥

易错初值用 arr[0]；结果写进 *pt1、*pt2。

#include <stdio.h>

void maxmin(int arr[], int *pt1, int *pt2, int n)
{
    int i;
    *pt1 = *pt2 = arr[0];
    for (i = 1; i < n; i++) {
        if (arr[i] > *pt1) *pt1 = arr[i];
        if (arr[i] < *pt2) *pt2 = arr[i];
    }
}

#define N 10

int main(void)
{
    int array[N] = {10, 7, 19, 29, 4, 0, 7, 35, -16, 21}, *p1, *p2, a, b;
    p1 = &a;
    p2 = &b;
    maxmin(array, p1, p2, N);
    printf("max=%d,min=%d\n", a, b);
    return 0;
}

运行结果

max=35,min=-16

题4有序插入函数

综合 · 2018 第5题（20 分）

编写程序实现在一个按照升序排序的数组中查找 x 应插入的位置，并将 x 插入数组中，使得数组元素仍按照升序排列，输出插入后的数组。原数组和 x 值由键盘输入，插入操作用函数实现。

要求

insert(arr, n, x)：arr 里有 *n 个升序的数（后面有空位），把 x 插进去，并把 *n 加 1（主函数调用：insert(arr, &n, x);）。

  • 思路和环06 题3 一样，只是长度改成通过指针带回。加 1 要写 (*n)++。

对应讲义　⑦ 细10

易错用 *n 当长度；最后 (*n)++。

#include <stdio.h>

void insert(int arr[], int *n, int x)
{
    int pos = 0, i;
    while (pos < *n && arr[pos] < x) pos++;
    for (i = *n; i > pos; i--) arr[i] = arr[i - 1];
    arr[pos] = x;
    (*n)++;
}

int main(void)
{
    int arr[101], n, x, i;
    scanf("%d", &n);
    for (i = 0; i < n; i++) scanf("%d", &arr[i]);
    scanf("%d", &x);
    insert(arr, &n, x);
    for (i = 0; i < n; i++) printf("%d ", arr[i]);
    printf("\n");
    return 0;
}

输入

5
1 3 5 7 9
6

运行结果

1 3 5 6 7 9

题5矩阵函数

限时 · 2012 第6题 · 限时 15 分钟

从键盘上输入两个 3×3 的矩阵，分别求出这两个矩阵的转置结果及两个矩阵的和，并输出。要求：

（1）设计函数 InputMatrix，用于实现矩阵输入；

（2）设计函数 ReverseMatrix，用于实现矩阵转置；

（3）设计函数 AddMatrix，用于实现两个矩阵和；

（4）设计函数 OutputMatrix，用于实现矩阵输出，在屏幕上显示；

（5）设计主函数 main，分别调用这些自定义函数进行测试。

要求

写下面三个：

ReverseMatrix(a, b)：把 a 的转置放进 b（a 不变）。注意是转置，不是旋转 180 度。

AddMatrix(a, b, c)：c = a + b。

OutputMatrix(a)：每行 3 个数，数之间一个空格，每行末尾换行。

对应讲义　⑧ 环07 ③

易错注意：真题的参考程序把 ReverseMatrix 写成了 180 度旋转，那是错的；转置是 b[j][i] = a[i][j]。

#include <stdio.h>

void ReverseMatrix(int a[][3], int b[][3])
{
    int i, j;
    for (i = 0; i < 3; i++)
        for (j = 0; j < 3; j++)
            b[j][i] = a[i][j];
}

void AddMatrix(int a[][3], int b[][3], int c[][3])
{
    int i, j;
    for (i = 0; i < 3; i++)
        for (j = 0; j < 3; j++)
            c[i][j] = a[i][j] + b[i][j];
}

void OutputMatrix(int a[][3])
{
    int i, j;
    for (i = 0; i < 3; i++) {
        for (j = 0; j < 3; j++) printf(j ? " %d" : "%d", a[i][j]);
        printf("\n");
    }
}

void InputMatrix(int a[][3])
{
    int i, j;
    for (i = 0; i < 3; i++)
        for (j = 0; j < 3; j++) scanf("%d", &a[i][j]);
}

int main(void)
{
    int a[3][3], b[3][3], ta[3][3], tb[3][3], sum[3][3];
    InputMatrix(a);
    InputMatrix(b);
    ReverseMatrix(a, ta);
    ReverseMatrix(b, tb);
    AddMatrix(a, b, sum);
    printf("A 的转置：\n");  OutputMatrix(ta);
    printf("B 的转置：\n");  OutputMatrix(tb);
    printf("A + B：\n");     OutputMatrix(sum);
    return 0;
}

输入

1 2 3
4 5 6
7 8 9
1 1 1
2 2 2
3 3 3

运行结果

A 的转置：
1 4 7
2 5 8
3 6 9
B 的转置：
1 2 3
1 2 3
1 2 3
A + B：
2 3 4
6 7 8
10 11 12

编程题怎么写

一个结果用 return 交回来；要改调用者的变量、或者要带回好几个结果，就用指针参数。

通用骨架

double area(double top, double bottom, double h);   // 原型：写在 main 前面

int main(void)
{
    double a, b, h;
    scanf("%lf%lf%lf", &a, &b, &h);
    printf("%.2f\n", area(a, b, h));                // 调用
    return 0;
}

double area(double top, double bottom, double h)     // 定义
{
    return (top + bottom) * h / 2;
}

①原型、定义、调用

  • 原型（声明）：double area(double top, double bottom, double h);，以分号结尾，写在 main 前面，告诉编译器「有这么个函数，要三个 double，给回一个 double」。
  • 定义：真正的函数体。
  • 调用：area(3, 5, 4)，得 16.00。

三处的返回类型、参数个数和类型要一致。把整个定义写在 main 前面，就可以不写原型。

②return 交回结果；printf 只是打印

return 把结果交回调用的地方，调用处可以接住、再用；函数里 printf 只是打到屏幕上，调用处拿不到。

题目说「编写函数求……」，一般都是 return 结果，由 main 输出。

返回值会按函数的返回类型转换：int 函数里 return 2.9;，调用处得到 2。

③函数拿到的是复制品

int bump(int x) { x++; return x; }

a = 3;
bump(a);          // a 还是几？
a = bump(a);      // 现在呢？

bump(a); 之后 a 是 3：函数改的是自己的 x，x 是 a 的复制品；返回值也没人接。a = bump(a); 之后 a 是 4。

这就是「单向值传递」：实参的值复制给形参，形参怎么改都传不回去。

④指针：存地址的变量

&x 是 x 的地址。int *p = &x; 让 p 存着 x 的地址，之后 *p 就是 x 本身：

int x = 5, *p = &x;
*p = 8;           // 等于 x = 8

执行后 x 是 8。

两个 * 意思不一样：定义时 int *p 的 * 表示「p 是指针」；用的时候 *p 表示「p 指着的那个变量」。

⑤想改调用者的变量：传地址进去

传值（换不了）
void swap(int a, int b)
{
    int t = a; a = b; b = t;
}
// 调用：swap(x, y);
传地址（能换）
void swap(int *a, int *b)
{
    int t = *a; *a = *b; *b = t;
}
// 调用：swap(&x, &y);

x = 1、y = 2：左边调用后 x、y 是 1、2，换的是复制品；右边是 2、1。

右边两个容易错的地方：

  • 中间变量是普通的 int t，不是 int *t。int *t; *t = *a; 里 t 没指向任何地方，往那里写是未定义行为。
  • 要交换的是 *a 和 *b（两个变量的值），不是 a 和 b（那只是换了函数里的两个地址副本）。

⑥多个结果：用指针参数带回

return 只能交回一个值。题3 要同时求最大值和最小值，就让 main 把两个变量的地址传进来：

void maxmin(int arr[], int *pmax, int *pmin, int n);

// main 里：
maxmin(arr, &mx, &mn, 10);
printf("max=%d,min=%d\n", mx, mn);

函数里对 *pmax、*pmin 赋值，就是对 main 的 mx、mn 赋值。函数体留给你写，思路和环06 找最小值一样。

⑦数组参数：能改元素；要改长度就再传 &n

数组传进去的是地址，函数能直接改元素（环06 细6）。但长度 n 是个普通 int，要在函数里让它加 1，就得传 &n：

void append(int a[], int *n, int x)
{
    a[*n] = x;
    (*n)++;            // 不能写 *n++，见细10
}
// main 里：append(a, &n, 9);

a = {1, 2, 3}、n = 3，调用后 n 是 4，a[3] 是 9。

⑧二维数组参数：列数必须写

int total(int m[][3], int rows)
{
    int i, j, s = 0;
    for (i = 0; i < rows; i++)
        for (j = 0; j < 3; j++) s += m[i][j];
    return s;
}

int m[2][3] = {{1, 2, 3}, {4, 5, 6}};，total(m, 2) 得 21。

形参的列数必须写，而且要和实参一样（环07 细6）。

函数和变量的规矩

这部分以概念选择题为主。每一节最后附了真题的问法。

细1函数不能嵌套定义，可以嵌套调用

在一个函数里面再定义一个函数，不行；在一个函数里调用另一个函数，可以，fun(fun(x)) 也可以。

不写返回类型，教材按 int 处理（C99 起标准取消了这个规定，编译器会报错或警告，平时要写全）。

真题里这样考

函数里能不能定义另一个函数 → 不能配-2-9

fun(fun(x)) 合法吗 → 合法，是嵌套调用配-2-7

细2先声明，后调用

定义写在 main 后面时，main 前面要有原型。原型可以省掉形参名：double area(double, double, double); 也对。

void 函数没有返回值，t = fun(…); 这样接是编译错误。

真题里这样考

void fun(char ch, float x[]); float a[5]; 正确的调用 → 题面存疑，见下真选11·武科大2019

真选11 原书答案 B 写成 t = fun('D', a);，可 fun 是 void，这样赋值是错的，题面应是 fun('D', a);。其他选项：A fun("a", a[]) 实参写法错；C '65' 不是合法字符；D a[5] 是一个元素不是数组。

细3形参是函数自己的局部变量

实参可以是常量、变量、表达式；形参只能是变量。形参在调用时才分配空间，调用结束就释放。

「实参和形参之间是单向值传递」：传指针也一样，只是这次复制过去的值是一个地址。

真题里这样考

「在一个函数的复合语句中定义的变量，在本函数范围内有效」 → 错，只在那个复合语句里有效真选22·华南理工2018

细4作用域：变量在哪里能用

局部变量只在定义它的 {} 里有效。同名时，里面的盖住外面的：

int g = 9;                     // 全局
int read_g(void) { return g; }

int main(void)
{
    int g = 1;                 // 盖住了全局 g
    { int g = 2; printf("%d ", g); }
    printf("%d ", g);
    printf("%d", read_g());
}

输出 2 1 9：内层块的 g 是 2；出了内层块是 main 的 1；read_g 里没有局部 g，用的是全局的 9。

不同函数可以用同名变量，互不相干。全局变量从定义的位置往后，所有函数都能用。

细5static 局部变量：只初始化一次

普通局部变量
int plain(void)
{
    int n = 0;
    n++;
    return n;
}
static 局部变量
int counter(void)
{
    static int n = 0;
    n++;
    return n;
}

各调用三次：plain 得 1 1 1，counter 得 1 2 3。static 变量只在第一次初始化，函数结束后值还留着。

static 局部变量的作用域还是只在函数里，只是寿命变长了。局部 static 和全局变量不初始化时自动为 0。

void ff(void)
{
    int c = 9;
    static int a = 1, b = 4;
    if (b == 4) { a += c; b++; }
    else        { a += c; b--; }
    printf("a=%d,b=%d  ", a, b);
}
// main 里：ff(); ff();

输出 a=10,b=5 a=19,b=4。

细6存储类别：auto、static、register、extern

  • auto：局部变量和形参默认都是 auto。
  • static：见细5。全局变量前加 static，只能在本文件里用。
  • register：建议放进寄存器；不能对它取地址 &。
  • extern：声明「这个变量在别处定义了」，不再分配空间。

函数也分内外：函数前加 static 是内部函数，只能本文件调用；不加就是外部函数，别的文件也能调用。

真题里这样考

形参的缺省存储类别 → auto真选46·川大2017

细7一句里调用好几次：顺序没规定

printf("%d %d %d", counter(), counter(), counter());

可能输出 3 2 1，也可能输出 1 2 3：C 标准没规定实参先算哪个（未指定行为）。读程序题遇到要指出「顺序不确定」；自己写程序就拆成几句。

细9& 和 * 是一对

&x 取地址，*p 取指向的值，*&x 就是 x。

int *p, m = 5, n = 0; p = &n; *p = m;→n = 5 等于 n = m p = &n; scanf("%d", p);对 p 本身就是地址，不再加 & scanf("%d", n);错 要地址给了整数 p = n;错 整数不能给指针 int *p, *s; s = &p;错 &p 是「指针的地址」，类型不对

细10*n++ 不是 (*n)++

*q++ 等于 *(q++)：取 q 原来指着的值，然后 q 自己往后挪。(*q)++ 才是让 q 指着的那个变量加 1。

int a[3] = {10, 20, 30}, *q = a, v;
v = *q++;          // ①
v = (*q)++;        // ②

① 之后 v = 10，q 指向 20；② 之后 v = 20，a[1] 变成 21。

所以题4 里让长度加 1，要写 (*n)++、++*n 或 *n = *n + 1。写 *n++ 是让指针 n 挪走了，长度没变，测试会专门提示这个错。

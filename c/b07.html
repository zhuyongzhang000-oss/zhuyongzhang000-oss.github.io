方法

读程序题的八个工具，加上原卷基础题的易错点。自测题后面的「→ ③」就是这里的节号。

①追踪表：一列一个变量，一行一步

不要在脑子里跑循环。在草稿纸上画表，每执行完一句（或一轮循环）写一行：

y（循环前）x（循环前）走了哪个分支x（之后）
11奇数：x += 5，continue6
26偶数：x −= 33
33奇数8
48偶数5
55奇数10
610x >= 10：break10

这是期末卷 2016-17 三-3。continue 之后还会执行 y++（for 的第三部分），break 不会——所以最后 y 是 6。

do { … } while (b-- < 0); 这种条件里带 ++/−− 的：条件判断完，b 已经减了，不管条件真假（环04 细3）。

②递归：一层一行，往下写参数，往回写返回值

show(5)  打印 5
  show(3)  打印 3
    show(1)  打印 1
      show(-1)  什么都不做，返回
    回到 show(1)：打印 1
  回到 show(3)：打印 3
回到 show(5)：打印 5          → 531135

递归调用前面的语句在「往下走」时执行，后面的语句在「往回走」时执行，顺序是反的（环10 ③）。

参数里还有递归（ack(m − 1, ack(m, n − 1))）：先把里面那个算完，得到一个数，再调用外面那个。层数多时在每一行旁边写「等 ack(1,0) 的结果」，算出来再回填。

期末卷 2016-17 三-4 的 rev(m, n)：每层交换首尾两个，然后 m + 1、n − 2 往里缩。数组后 3 个元素从没被碰过，还是 0。

③static：只在第一次之前初始化一次

int fs(int a, int b)
{
    static int m = 0, i = 2;   // 这一句只在程序开始时生效一次
    i += m + 1;
    m = i + a + b;
    return m;
}

调用两次 fs(4, 1)：第一次 i = 3、m = 8；第二次 i 从 3 开始 += 9 得 12，m = 17。auto 变量（普通局部变量）每次进函数都重新初始化。

同名变量：形参、局部变量和全局变量同名时，函数里用的是离得最近的那个；形参是复制品，改它不影响全局变量（环09 细4）。2012 原卷四-1 三个 y 同名：全局 5、main 里 3、形参是复制品，输出里的 y 和全局的 5 没有关系。

2016 年考过 10 分的简答「static 全局变量和普通全局变量、static 局部变量和普通局部变量有什么区别」，按下面四条答：

存在哪、活多久作用域（谁能用）不赋初值时
普通局部变量栈上，函数调用结束就释放本函数（本复合语句）不确定
static 局部变量静态存储区，程序运行期间一直在本函数，但值保留到下次调用0，而且只初始化一次
普通全局变量静态存储区从定义处到文件末尾；别的文件 extern 声明后也能用0
static 全局变量静态存储区只在本文件，别的文件用不了0

④指针：先加括号，再画箭头

单目运算符从右往左结合：

*p++→*(p++) 取原来的值，p 往后 *++p→*(++p) p 先往后，再取 ++*p→++(*p) 指的那个值加 1，p 不动 (*p)++→值加 1（先用后加），p 不动

期末卷 2016-17 二-3：p += 2, *(p++) 的值是 3；p += 2, ++*p 的值是 4，但 a[2] 也被改成了 4。

while (*y++); 停下时 y 已经越过了 '\0' 一格，所以 y − x − 1 才是长度（期末卷 2018-19 二-4，求字符串长度）。

for 的循环体如果是一个 do-while（期末卷 2019-20 四-4 的 strc），先找准哪一段是循环体，再追踪：for 只判断了一次，do-while 一口气把 s2 抄完了。

⑤宏：一个字不改地替换，再按优先级算

#define MUL(a, b) a * b，MUL(2 + 3, 4 − 1)→2 + 3 * 4 − 1 = 13 #define MIN(x, y) (x) < (y) ? (x) : (y)，10 * MIN(2, 3)→10 * (2) < (3) ? (2) : (3) = 3 外面没括号 #define M N + 1，#define NUM 2 * M + 1，N 是 2→NUM 是 2 * 2 + 1 + 1 = 6

步骤：先展开、写出来，再算。宏套宏一层一层展开，每层都不加括号。参数里有 i++ 的，展开后 i++ 可能出现两次——这是未定义行为（⑥）。

⑥求值顺序：哪些有规定，哪些没有

有规定的（可以放心追踪）：

  • &&、|| 从左到右，并且短路；?: 先算条件；逗号运算符从左到右，值是最后一个。
  • 一句结束（分号）时，前面的 ++、−− 都已经完成。

没有规定的（考试会以选择题、判断题的形式问「结果是什么」或「对不对」）：

  • 函数参数的计算顺序：printf("%d %d", i, i++) 不同编译器结果不同。
  • 同一个表达式里改同一个变量两次：a += a -= a * a、i = i++、SQ(i++)，都是未定义行为。考试题给出的答案一般按「从右往左」算（a += a −= a * a，a 为 3 时得 −12），但自己写程序绝不要这样写。

scanf 的返回值是成功读入了几个：读 %d 遇到 # 返回 0，这正是 2012④「输入到 # 结束」最简单的写法：while (scanf("%d", &x) == 1)。

⑦结构体指针：-> 和 . 比 ++、* 都先结合

++p->x→++(p->x) 改的是成员，p 不动 (++p)->x→p 先指向下一个元素，再取 x p->y++→(p->y)++ 先用 y 的值，y 再加 1 *p->name→*(p->name) name 的第一个字符 *p.age→*(p.age) 编译出错：p 是指针，要写 (*p).age

⑧二维数组：a + i 是一行，a[i] + j 是一个元素的地址

int a[3][4], (*p)[4] = a;：

*(*(p + 1) + 2)→a[1][2] (*(p + 2))[1]→a[2][1] **p + 1→a[0][0] + 1 先取值再加 1 *(p + 1)[2]→*(p + 3)，越界 [] 比 * 先结合

二维数组按行连续存放（环07 细4），所以 int *q = &a[0][0]; 以后，q[i × 列数 + j] 就是 a[i][j]。3 × 3 的主对角线是 q[0]、q[4]、q[8]。

⑨原卷的填空、选择、判断：这几处最容易丢分

2012、2013 考研原卷的基础题比期末卷还基础，丢分都丢在下面这些「以为会了」的地方：

'c' 和 "c"→1 个字节和 2 个字节 字符串末尾还有 '\0' enum { a1, a2 = 4, a3, a4 = 10 }→a1 = 0，a3 = 5 没写值的接着前一个加 1 5 % 2、5.0 % 2→1、编译出错 % 只能用于整数 y = x >= 0 ? x : -x;→y 是 x 的绝对值 ?: 优先级很低，几乎最后算 strcat(s, " Sun!")，s 原来是 "My"→"My Sun!" 接在 s 的 '\0' 那里，s 要够大
  • 大小写互换：大写 + 32 变小写，小写 − 32 变大写（'a' − 'A' = 32）。注意要写成 if … else if …：写成两个独立的 if，大写字母加 32 变成小写以后，又被第二个 if 减回去。
  • 判断小写字母：c >= 'a' && c <= 'z'。'a' <= c <= 'z' 语法能过，但意思是 ('a' <= c) <= 'z'，永远为真。
  • 两个字符串逐个比，停下来的位置相减：ch1[i] - ch2[i]，是两个字符的 ASCII 码之差，a 是 97，t 是 116。
  • 定义数组长度要用常量：int n; int arr[n]; 考试按「不行」答（C89），用 #define N 10。
  • 构成 C 程序的基本单位是函数；main 和库函数的名字不是用户起的。

考场上

读程序题的答题习惯。

细1输出格式照抄

printf 里的逗号、空格、\n、%3d 的宽度都要写进答案。%3d 输出 1 是两个空格加 1。期末卷 2018-19 四-4 的结果就是 1 3 4。

细2题目代码有问题时

期末卷的代码常有老写法（main() 不写 int、函数不写返回类型）和转写错误。先判断是不是故意的：是故意的（比如 if (x = y + z) 是赋值），就按 C 的规则走；明显是印刷错误，就按最合理的意思做，并在答案旁写一句说明。

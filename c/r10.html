递归

递归就是函数调用自己。只要守住两件事：有一个不用再调用的最小情况（基例），每次调用规模都变小。前半份讲递归怎么写、怎么读；后半份讲预处理（#define、#include），读程序题里宏展开很常考。

题1猴子吃桃

代表题 · 教材第5章习题12（改编：要求用递归）

猴子吃桃问题。猴子第 1 天摘下若干个桃子，当即吃了一半，还不过瘾，又多吃了一个。

第 2 天早上又将剩下的桃子吃掉一半，又多吃了一个。以后每天早上都吃了前一天剩下的一半零一个。

到第 10 天早上想再吃时，就只剩下一个桃子了。求第 1 天共摘多少个桃子。

要求

peach(day) 返回第 day 天早上（还没吃时）有几个桃子，必须用递归。

peach(10) 是 1；题目要的答案是 peach(1)。

  • 思路先写出「今天的」和「明天的」的关系；基例是第 10 天。

对应讲义　① ⑤

易错关系：今天 = (明天 + 1) * 2；基例第 10 天是 1。

#include <stdio.h>

int peach(int day)
{
    if (day == 10) return 1;
    return (peach(day + 1) + 1) * 2;
}

int main(void)
{
    printf("第 1 天共摘了 %d 个桃子\n", peach(1));
    return 0;
}

运行结果

第 1 天共摘了 1534 个桃子

题2整数转字符串

变式 · 教材第7章习题17

用递归法将一个整数 n 转换成字符串。例如，输入 483，应输出字符串 "483"。

n 的位数不确定，可以是任意位数的整数。

要求

convert(n) 用递归把 n 的每一位当字符输出（用 putchar 或 printf("%c")），不换行。

负数先输出 '-'；0 输出 "0"。

  • 思路先递归处理 n/10，再输出 n%10 对应的字符（'0' + n%10）。

对应讲义　③ ④

易错先递归后输出，高位才在前；负数先处理符号。

#include <stdio.h>

void convert(int n)
{
    if (n < 0) { putchar('-'); n = -n; }
    if (n >= 10) convert(n / 10);
    putchar('0' + n % 10);
}

int main(void)
{
    int n;
    scanf("%d", &n);
    convert(n);
    printf("\n");
    return 0;
}

输入

483

运行结果

483

题4勒让德

综合 · 教材第7章习题13

用递归方法求 n 阶勒让德多项式的值，递归公式为：

P_n(x) = 1                                             （n = 0）
P_n(x) = x                                             （n = 1）

P_n(x) = ((2n-1)·x·P_{n-1}(x) - (n-1)·P_{n-2}(x)) / n （n > 1）

说明：原书公式是图片看不清，上面是通行的勒让德递推式，Notion 题库里标了「存疑」。

要求

legendre(n, x) 返回 P_n(x)。

  • 注意两个基例都要写；(2n-1) 和 (n-1) 是整数，乘上 double 才变 double，最后除以 n 要保证是小数除法。

对应讲义　⑦

易错两个基例；n 是 int，但式子里有 double 的 x，整体按 double 算。

#include <stdio.h>

double legendre(int n, double x)
{
    if (n == 0) return 1;
    if (n == 1) return x;
    return ((2 * n - 1) * x * legendre(n - 1, x) - (n - 1) * legendre(n - 2, x)) / n;
}

int main(void)
{
    int n;
    double x;
    scanf("%d%lf", &n, &x);
    printf("P%d(%g) = %f\n", n, x, legendre(n, x));
    return 0;
}

输入

3 0.5

运行结果

P3(0.5) = -0.437500

题5拉丁方阵

限时·难 · 2023 第2题 · 限时 25 分钟

拉丁方阵定义：一个 n×n 的方阵，满足：每一行包含数字 1 到 n，且不重复；每一列也包含数字 1 到 n，且不重复。要求输出所有可能的 n×n 拉丁方阵。

要求

latin(n) 输出所有 n×n 拉丁方阵（n <= 4）：

每个方阵占 n 行，数之间一个空格；每个方阵后面空一行；最后一行输出 "共 k 个"。

顺序规定：按行从左到右一格一格填，每格从 1 试到 n（这样输出顺序是唯一的）。

例如 n=2：

1 2
2 1
2 1
1 2

共 2 个

  • 思路回溯。可以在本文件里自己再写辅助函数和全局数组（加 static 更好）。

对应讲义　⑧

易错一格一格填（pos = 0 ~ n*n-1）；每格从 1 试到 n；行列都没出现过才填；回来后撤销。

#include <stdio.h>

static int sq[4][4], N, total;

static int ok(int row, int col, int v)
{
    int k;
    for (k = 0; k < col; k++) if (sq[row][k] == v) return 0;   /* 这一行前面 */
    for (k = 0; k < row; k++) if (sq[k][col] == v) return 0;   /* 这一列上面 */
    return 1;
}

static void fill(int pos)
{
    int row = pos / N, col = pos % N, v, i, j;
    if (pos == N * N) {                       /* 填满了：输出一个 */
        for (i = 0; i < N; i++) {
            for (j = 0; j < N; j++) printf(j ? " %d" : "%d", sq[i][j]);
            printf("\n");
        }
        printf("\n");
        total++;
        return;
    }
    for (v = 1; v <= N; v++)
        if (ok(row, col, v)) {
            sq[row][col] = v;
            fill(pos + 1);
            sq[row][col] = 0;                 /* 撤销，试下一个值 */
        }
}

void latin(int n)
{
    N = n;
    total = 0;
    fill(0);
    printf("共 %d 个\n", total);
}

int main(void)
{
    int n;
    scanf("%d", &n);
    latin(n);
    return 0;
}

输入

3

运行结果

2 3 1
3 1 2

1 2 3
3 1 2
2 3 1

⋯（共 49 行，中间省略）

编程题怎么写

写递归先写基例，再写「怎么用小一号的答案拼出这一号的答案」。

通用骨架

类型 f(规模 n)
{
    if (基例) return 直接给出的答案;      // 先写这一句
    return 用 f(更小的 n) 拼出答案;       // 规模必须变小
}

①递归两件事：基例、规模变小

int sum_to(int n)
{
    if (n == 0) return 0;              // 基例
    return n + sum_to(n - 1);          // 规模变小
}

sum_to(3) = 3 + sum_to(2) = 3 + 2 + sum_to(1) = 3 + 2 + 1 + sum_to(0) = 6。

没有基例，或者规模不变小（比如 return f(n);），就会无限调用下去，最后程序崩溃。

②每一层是一次新的调用

每次调用都有自己的 n 和局部变量，互不影响。sum_to(3) 的过程：

进入 n=3 → 进入 n=2 → 进入 n=1 → 进入 n=0
                                  n=0 返回 0
                      n=1 返回 1 + 0 = 1
          n=2 返回 2 + 1 = 3
n=3 返回 3 + 3 = 6

一层层下去，到基例后再一层层回来。读递归程序就画这张表。

③打印写在递归前面还是后面

先打印再递归
void down(int n)
{
    if (n == 0) return;
    printf("%d ", n);
    down(n - 1);
}
先递归再打印
void up(int n)
{
    if (n == 0) return;
    up(n - 1);
    printf("%d ", n);
}

down(4) 输出 4 3 2 1，up(4) 输出 1 2 3 4。

左边是「往下走的时候打印」；右边是「先一路走到底，回来的时候才打印」，所以顺序反过来了。

④整数从高位往低位输出

拆位（环02 ①）出来的顺序是个位在前。想让高位在前，就用 ③ 的右边那种：先递归处理 n / 10（前面那几位），再输出 n % 10（个位）。

483：先处理 48（它又会先处理 4、再输出 8），最后输出 3。所以输出 483，不用数组倒序。

数字变成字符输出，要写 '0' + n % 10（回顾里那道）。

⑤逆推：从最后一天往前推

猴子吃桃：每天吃一半再多吃一个，第 10 天早上只剩 1 个。

先写出「今天」和「明天」的关系：今天吃完剩下的就是明天的，明天 = 今天 / 2 − 1，所以 今天 = (明天 + 1) × 2。

基例是第 10 天，答案 1。peach(day) 就是用 peach(day + 1) 算出来的。写完核对：第 1 天是 1534 个。

这里规模「变小」的方向是 day 变大，往第 10 天靠，一样能停下来。

⑥调用自己两次：Hanoi 塔

n 个盘从 A 借 B 移到 C，三步：上面 n − 1 个先挪到 B；最大的从 A 移到 C；B 上的 n − 1 个再挪到 C。

void hanoi(int n, char from, char via, char to)
{
    if (n == 1) { printf("%c->%c ", from, to); return; }
    hanoi(n - 1, from, to, via);
    printf("%c->%c ", from, to);
    hanoi(n - 1, via, from, to);
}

n = 3 一共 7 步（2ⁿ − 1），第一步是 A->C。

⑦用到前两项：要写两个基例

Fibonacci：f(n) = f(n−1) + f(n−2)，f(1) = f(2) = 1。f(7) = 13。

公式里用到 n − 1 和 n − 2 两项，基例就要写两个。只写 f(1)，算 f(2) 时会去算 f(0)、f(−1)……停不下来。

勒让德多项式也是这样：P₀ = 1，P₁ = x，Pₙ = ((2n − 1)·x·Pₙ₋₁ − (n − 1)·Pₙ₋₂) / n。注意最后除以 n 要是小数除法（环01 ①）。

⑧回溯：一格一格试，不行就撤回

拉丁方阵：每行、每列都是 1 到 n 且不重复。按格子编号 pos 一格一格填：

void fill(int pos)                       // pos 是第几格，0 到 n*n-1
{
    if (pos == n * n) { 输出整个方阵; return; }
    row = pos / n;  col = pos % n;
    for (v = 1; v <= n; v++)
        if (v 在这一行、这一列都没出现过) {
            a[row][col] = v;
            fill(pos + 1);               // 填下一格
            a[row][col] = 0;             // 撤回，试下一个 v
        }
}

row = pos / n; col = pos % n; 又是环01 的整除和取余：n = 3 时第 5 格在第 1 行第 2 列（从 0 数）。

学长的参考程序每层都从第 0 列重新扫，会重复搜索，结构有误，不要照抄。

预处理

以 # 开头的行都是预处理命令。读程序题里，宏展开是最常考的。

细1#define：编译前原样替换

#define N 5 的意思是：编译之前，把程序里的 N 原样换成 5。宏名习惯大写。

它不是变量，不占内存，也不能被赋值：N = 6; 替换后是 5 = 6;。

#define N 5; 多了分号：int a[N]; 会变成 int a[5;];，编译错误。

字符串里的不替换："N" 还是 "N"。

细2带参数的宏：先原样展开，再算

宏只做文字替换，不会先把参数算出来。做法：把参数原样抄进去，再按优先级算：

#define SQ1(x) x * x 时 SQ1(1 + 2)→5 展开成 1 + 2 * 1 + 2 #define SQ2(x) ((x) * (x)) 时 SQ2(1 + 2)→9 
#define CANBERRA(x, y) ((x - y) / (x + y))
CANBERRA(1.0 + 2.0, 0.0 + 2.0)

展开成 ((1.0 + 2.0 - 0.0 + 2.0) / (1.0 + 2.0 + 0.0 + 2.0))，值是 1.0。

宏名和左括号之间不能有空格：#define SQ (x) x*x 会变成「把 SQ 换成 (x) x*x」。

细3宏和函数的区别

  • 宏在编译前展开；函数在运行时调用。
  • 宏不检查类型；函数的参数有类型。
  • 宏的参数不先求值，原样替换；函数先把实参算出来再传。

细4宏的参数里有 ++，可能被算两次

#define MAX(a, b) ((a) > (b) ? (a) : (b))
i = 5; j = 3;
m = MAX(i++, j);       // 展开：((i++) > (j) ? (i++) : (j))

m = 6，i = 7：i++ 在条件里算了一次，选中以后又算了一次。函数就不会这样。

细5#include 的两种写法

  • #include <文件>：先去系统目录找。标准库用这种。
  • #include "文件"：先在当前目录找，找不到再去系统目录。自己写的头文件用这种。

#include 也是预处理命令，末尾同样没有分号（环01 细13）。

细6条件编译：条件为假的代码不编译

#if 条件 … #endif：条件为假，中间的代码根本不参与编译。#if 0 … #endif 常用来临时屏蔽一段代码。

#ifdef 宏名 / #ifndef 宏名：这个宏定义过（没定义过）才编译。头文件开头常用 #ifndef 防止被重复包含。

细7预处理在编译之前

预处理由预处理器在编译之前完成，不是在程序运行时。以 # 开头的行才是预处理命令。

细8递归改错：if (n = 1)

题3 的原程序有两处错：

  • fun(n) 没写返回类型和形参类型，要改成 int fun(int n)；
  • if (n = 1) 是赋值，永远为真，基例永远成立，要改成 if (n == 1)。

改对之后，fun(1) = 10，fun(n) = fun(n − 1) + 2，fun(5) = 18。

int f(int n) { if (n <= 1) return 1; return n * f(n - 2); }

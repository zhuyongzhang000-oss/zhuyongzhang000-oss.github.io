题1最大次大和次数

必做 · 2013 第3题、2014 第4题的升级（原题 15 分）

一次遍历数组，同时求出最大值、最大值出现了几次、次大值（比最大值小的数里最大的那个）。

要求

top2(a, n, &first, &cnt, &second)：结果用后三个指针带回；n >= 1。

有次大值返回 1；所有数都一样（包括 n == 1）时没有次大值，返回 0，这时 second 指向的变量不要改。

例如 {3, 9, 2, 9, 1}：first = 9，cnt = 2，second = 3，返回 1。

要求用指针遍历（p 从 a 走到 a + n），不用下标。

  • 依据2013③/2014④「用指针作函数参数，求一维数组中的最大和最小的元素值」；52 道真题里 5 道要求指针参数，一个函数要交出好几个结果，只能靠指针带回。
  • 思路最大值、次数、次大值三个变量一起更新：遇到比最大还大的，原来的最大降为次大；等于最大的，次数加 1；比最大小、比次大大的，更新次大。次大「还没有」要单独用一个标记。

对应讲义　① ②

易错比最大还大时，旧的最大降成次大；「还没有次大」要单独记；所有数相同时不能改 *second。

#include <stdio.h>

int top2(const int *a, int n, int *first, int *cnt, int *second)
{
    const int *p;
    int mx = *a, c = 1, sec = 0, has = 0;
    for (p = a + 1; p < a + n; p++) {
        if (*p > mx) {
            sec = mx;  has = 1;                     /* 原来的最大降为次大 */
            mx = *p;   c = 1;
        } else if (*p == mx) {
            c++;
        } else if (!has || *p > sec) {
            sec = *p;  has = 1;
        }
    }
    *first = mx;
    *cnt = c;
    if (has) *second = sec;
    return has;
}

int main(void)
{
    int a[100], n, i, first, cnt, second;
    scanf("%d", &n);
    for (i = 0; i < n; i++) scanf("%d", &a[i]);
    if (top2(a, n, &first, &cnt, &second))
        printf("最大 %d（出现 %d 次），次大 %d\n", first, cnt, second);
    else
        printf("最大 %d（出现 %d 次），没有次大\n", first, cnt);
    return 0;
}

输入

6
2 8 8 5 8 7

运行结果

最大 8（出现 3 次），次大 7

题2字符串指针数组

必做 · 期末卷 + 教材第 8 章

names[0] ~ names[n-1] 是 n 个指向字符串的指针。

要求

两个函数。

(1) sort_names(names, n)：按字典序从小到大排序。

(2) find_name(names, n, key)：names 已经排好序，用二分查找找 key，找到返回下标，找不到返回 -1。

  • 依据川师本科期末卷 2016-17 二-4（char *aa[2] 指针数组）；教材 8.7 例题「将若干字符串按字母顺序输出」。
  • 思路(1) 冒泡或选择排序都行，比较用 strcmp(names[j], names[j + 1]) > 0，交换的是 char * 类型的临时变量。(2) 和环06 的二分一模一样，只是把 a[mid] 和 x 的比较换成 strcmp(names[mid], key)。

对应讲义　③

易错交换的是 char * 指针（不是 strcpy 搬字符串）；二分的比较用 strcmp 的正负。

#include <stdio.h>
#include <string.h>

void sort_names(char *names[], int n)
{
    int i, j;
    char *t;
    for (i = 0; i < n - 1; i++)
        for (j = 0; j < n - 1 - i; j++)
            if (strcmp(names[j], names[j + 1]) > 0) {
                t = names[j]; names[j] = names[j + 1]; names[j + 1] = t;
            }
}

int find_name(char *names[], int n, const char *key)
{
    int lo = 0, hi = n - 1, mid, c;
    while (lo <= hi) {
        mid = (lo + hi) / 2;
        c = strcmp(names[mid], key);
        if (c == 0) return mid;
        if (c < 0) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}

int main(void)
{
    char w[5][20], key[20], *names[5];
    int i, pos;
    for (i = 0; i < 5; i++) {
        scanf("%19s", w[i]);
        names[i] = w[i];
    }
    sort_names(names, 5);
    for (i = 0; i < 5; i++) printf("%s ", names[i]);
    printf("\n");
    scanf("%19s", key);
    pos = find_name(names, 5, key);
    if (pos >= 0) printf("%s 排在第 %d 个\n", key, pos + 1);
    else printf("没有 %s\n", key);
    return 0;
}

输入

pear apple fig app banana
fig

运行结果

app apple banana fig pear 
fig 排在第 4 个

题3函数指针排序

必做 · 期末卷 + 教材第 8 章

同一个排序函数，传进不同的「谁排在前面」的规则，就能排出不同的顺序。

要求

四个函数。

(1) sort_by(a, n, before)：按规则排序。before(x, y) 返回非 0 表示 x 应该排在 y 前面。

两个数谁在前都行（before(x, y) 和 before(y, x) 都是 0）时，保持它们原来的先后（稳定排序）。

(2) count_if(a, n, pred)：数组里有几个数让 pred(x) 返回非 0。

(3) by_abs(x, y)：规则「绝对值小的在前」。传给 sort_by，{3, -1, -3, 2} 排成 {-1, 2, 3, -3}。

(4) odd_first(x, y)：规则「奇数在前、偶数在后」，同为奇数或同为偶数时谁在前都行。

传给 sort_by，{4, 1, 6, 3, 5} 排成 {1, 3, 5, 4, 6}。

  • 依据川师本科期末卷 2016-17 一-7「int (*ptr)(); 则 ptr 是指向函数的指针」；教材 8.5 用函数指针作参数。
  • 思路(1) 冒泡排序，交换条件写成 before(a[j + 1], a[j])：后一个应该排在前一个前面才交换。这样相等时不动，就是稳定的。调用函数指针：before(x, y) 和 (*before)(x, y) 都可以。

对应讲义　④ ⑤

易错交换条件是「后一个应排在前一个前面」，相等不交换才稳定；比较函数返回 0/1，不是返回差。

#include <stdio.h>

void sort_by(int *a, int n, int (*before)(int x, int y))
{
    int i, j, t;
    for (i = 0; i < n - 1; i++)
        for (j = 0; j < n - 1 - i; j++)
            if (before(a[j + 1], a[j])) {
                t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
            }
}

int count_if(const int *a, int n, int (*pred)(int x))
{
    int k = 0;
    const int *p;
    for (p = a; p < a + n; p++)
        if ((*pred)(*p)) k++;
    return k;
}

int by_abs(int x, int y)
{
    int ax = x < 0 ? -x : x, ay = y < 0 ? -y : y;
    return ax < ay;
}

int odd_first(int x, int y)
{
    return x % 2 != 0 && y % 2 == 0;                /* 负奇数 % 2 是 -1，所以写 != 0 */
}

int is_even(int x) { return x % 2 == 0; }

int main(void)
{
    int a[] = {4, -7, 1, 6, -3, 5}, i;
    int (*rule)(int, int);
    printf("偶数有 %d 个\n", count_if(a, 6, is_even));
    rule = by_abs;
    sort_by(a, 6, rule);
    for (i = 0; i < 6; i++) printf("%d ", a[i]);
    printf("\n");
    sort_by(a, 6, odd_first);
    for (i = 0; i < 6; i++) printf("%d ", a[i]);
    printf("\n");
    return 0;
}

运行结果

偶数有 2 个
1 -3 4 5 6 -7 
1 -3 5 -7 4 6

题4行指针最大行

选做 · 期末卷原题的升级

n 行 4 列的整数矩阵，找出各元素之和最大的那一行。

要求

max_row(a, n, &sum)：返回和最大的那一行的首地址（几行一样大取最前面的），这一行的和用 sum 带回。

参数 a 写成行指针 int (*a)[4]：a + i 指向第 i 行，*(a + i) 或 a[i] 是第 i 行第 0 个元素的地址。

例如返回 a[2] 就是返回第 2 行（从 0 数）的首地址。

  • 依据川师本科期末卷 2016-17 四-3、2019-20 五-1「A 是一个 2×4 的整型数组……请编写 max_value 函数，函数原型是 max_value(int array[][4])」——二维数组作参数，两份期末卷都考了这一题。
  • 思路两重循环求每行的和；记住最大的是第几行 best，最后 return a[best];（类型正好是 int *）。注意和可能是负数：最大值的初值用第 0 行的和，不要用 0。

对应讲义　⑥

易错a[i] 是第 i 行首元素的地址（int *）；最大和的初值用第 0 行的和；用 > 保证取最前面的。

#include <stdio.h>

int *max_row(int (*a)[4], int n, int *sum)
{
    int i, j, s, best = 0, bs = 0;
    for (i = 0; i < n; i++) {
        s = 0;
        for (j = 0; j < 4; j++) s += a[i][j];
        if (i == 0 || s > bs) { bs = s; best = i; }
    }
    *sum = bs;
    return a[best];
}

int main(void)
{
    int m[3][4], i, j, s, *row;
    for (i = 0; i < 3; i++)
        for (j = 0; j < 4; j++) scanf("%d", &m[i][j]);
    row = max_row(m, 3, &s);
    printf("和最大的是第 %d 行，和为 %d：", (int)(row - m[0]) / 4 + 1, s);
    for (j = 0; j < 4; j++) printf("%d ", row[j]);
    printf("\n");
    return 0;
}

输入

1 2 3 4
5 6 7 8
9 0 0 1

运行结果

和最大的是第 2 行，和为 26：5 6 7 8

开始之前，先回想一下

这些是前面学过、这一环又要用到的基础。想不起来就回到出处那一节再看一眼。

想让函数改 main 里的 x，调用时传 → &x，函数里用 *p环09 ⑤

一个函数要交出两个结果 → 用指针参数带回环09 ⑥

int *p[4] 和 int (*p)[4] → 前者是 4 个指针的数组，后者是指向一行（4 个 int）的指针环11 细7

int (*f)(int, int); 的 f 是 → 指向函数的指针环11 细8

strcmp("app", "apple") → 负数（前缀短的小）环08 细5

套路

接口题先把函数头写对，再写函数体。

①多个结果：指针带回，返回值报「成没成」

一个函数要交出好几个结果：结果都用指针参数带回，返回值留给「状态」——找没找到、有没有解、成不成功。

int top2(const int *a, int n, int *first, int *cnt, int *second);
//        输入            输出（调用时传 &x）            返回 1：有次大；0：没有

调用时：r = top2(a, n, &f, &c, &s);。函数里给结果赋值写 *first = mx;，first = mx; 只改了形参自己（环09 ③）。

「没有结果」时不要乱写输出参数。题1 规定没有次大就不改 *second，测试会检查。

②指针遍历：p 从 a 走到 a + n

const int *p;
for (p = a; p < a + n; p++)
    if (*p > mx) mx = *p;

const int *a 表示不会通过 a 改数组；p 也要写成 const int *，否则编译器会提醒。

找「次大」这类要同时维护几个量的题，先在纸上列出每种情况：比最大大 / 等于最大 / 比最大小但比次大大。漏掉第一种情况里「原来的最大降为次大」，{3, 9} 的次大就会找不到 3。

③字符串指针数组：交换指针，不搬字符串

char *names[5]：5 个指针，每个指向一个字符串。排序时交换的是指针：

交换指针（快，题目要的）
char *t;
t = names[j];
names[j] = names[j + 1];
names[j + 1] = t;
搬字符串（二维字符数组才这样）
char t[20];
strcpy(t, w[j]);
strcpy(w[j], w[j + 1]);
strcpy(w[j + 1], t);

指针数组里的指针如果指向字符串常量（char *n[] = {"pear", "fig"};），strcpy 搬字符串 会改常量，程序崩溃——只能交换指针。

二分查找字符串：c = strcmp(names[mid], key); c < 0 说明中间的小，去右半边。"appl" 是 "apple" 的前缀但不相等，strcmp 不为 0，所以找不到。

④函数指针：把「规则」当参数传

int (*before)(int x, int y);     // before 是指针，指向「两个 int 参数、返回 int」的函数
before = by_abs;                 // 函数名就是函数的地址，不用 &
if (before(a, b)) …             // 调用：before(a, b) 和 (*before)(a, b) 一样

作参数时写在形参表里：void sort_by(int *a, int n, int (*before)(int, int))，调用 sort_by(a, n, by_abs);。

括号不能少：int *f(int); 是返回 int * 的函数，不是函数指针。

⑤比较规则：返回 0/1；相等不交换才稳定

规则函数 before(x, y) 回答「x 该不该排在 y 前面」：

从大到小→return x > y; 绝对值小的在前→return abs(x) < abs(y); 奇数在前→return x % 2 != 0 && y % 2 == 0; 负奇数 % 2 是 −1，所以写 != 0

冒泡的交换条件写 before(a[j + 1], a[j])：后一个应该排前面才换。两个「一样」的数 before 两边都是 0，不交换，原来的先后保持不变——这叫稳定。写成 !before(a[j], a[j + 1]) 会把一样的也换掉，就不稳定了。

库函数 qsort 的比较函数是另一种约定（返回负、0、正），而且 qsort 不保证稳定。考试让写排序函数时用自己的冒泡。

⑥行指针：int (*a)[4] 和返回指针的函数

二维数组 int m[3][4] 作参数，函数头写 int a[][4] 和 int (*a)[4] 完全一样：a 指向「一行 4 个 int」。

a + i→第 i 行的地址（跳 4 个 int） a[i] 或 *(a + i)→第 i 行第 0 个元素的地址，类型 int * a[i][j] 或 *(*(a + i) + j)→元素

函数返回一行：return a[best];，返回类型是 int *。返回的地址指向 main 里的数组，函数结束后还有效。返回函数里局部数组的地址 不行，函数结束它就没了。

子数组也是指针：期末卷「从第 k 个数开始的 n 个数逆序」，把 a + k - 1 传给逆序函数，函数里就当成从 0 开始的 n 个数处理（环11 ④）。

写法辨认

选择题最爱考的几种声明。

细1声明从名字读起：先右后左，括号优先

从名字开始，先看右边（[] 是数组、() 是函数），再看左边（* 是指针）；有括号先读括号里的。

int *p[4]→p 是数组，4 个元素都是 int * int (*p)[4]→p 是指针，指向 4 个 int 的数组 int *f(int)→f 是函数，返回 int * int (*f)(int)→f 是指针，指向返回 int 的函数 int (*ptr)()→ptr 是指向函数的指针，该函数返回 int 川师卷2016-17 一-7

细2不能返回局部变量的地址

int *bad(void) { int x = 5; return &x; }   // x 在函数结束时就没了

编译能过（有警告），但用返回的指针去读是未定义行为。可以返回：形参传进来的数组里的地址、static 变量的地址、malloc 来的地址。

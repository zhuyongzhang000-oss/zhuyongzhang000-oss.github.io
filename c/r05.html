题1倒三角

代表题 · 2012 第2题

编程打印出如下图案。

*****
****
***
**
*

要求

triangle(n) 打印 n 行：第 1 行 n 个 *，每行少一个，最后一行 1 个；每行末尾换行。

真题就是 n=5。

  • 思路先列「第 i 行几个星号」的表，找出公式。

对应讲义　① ② ③

易错第 i 行（1 开始）有 n-i+1 个星号。

#include <stdio.h>

void triangle(int n)
{
    int i, j;
    for (i = 1; i <= n; i++) {
        for (j = 1; j <= n - i + 1; j++) printf("*");
        printf("\n");
    }
}

int main(void)
{
    triangle(5);
    return 0;
}

运行结果

*****
****
***
**
*

题2右移星号

变式 · 教材第1章习题5

编写一个 C 程序，运行时输出以下图形：

*****
 *****
  *****
   *****

（四行，每行 5 个星号，下一行比上一行右移一格）

说明：扫描版看不清每行到底右移几格，这里按「第 i 行前面 i 个空格（i 从 0 开始）」练。

要求

shifted(rows) 打印 rows 行，第 i 行（从 0 数）先打 i 个空格，再打 5 个 *，然后换行。

#include <stdio.h>

void shifted(int rows)
{
    int i, j;
    for (i = 0; i < rows; i++) {
        for (j = 0; j < i; j++) printf(" ");
        printf("*****\n");
    }
}

int main(void)
{
    shifted(4);
    return 0;
}

题3菱形

变式 · 教材第5章习题16

输出以下图案：

   *
  ***
 *****
*******
 *****
  ***
   *

要求

diamond(n) 打印上半 n 行、下半 n-1 行的菱形；真题是 n=4（中间那行 7 个 *）。

每行：前面的空格 + 星号，星号后面不要再打空格，然后换行。

  • 思路上半第 i 行（1~n）：n-i 个空格，2i-1 个星号；下半让 i 从 n-1 倒着走到 1，公式不变。

对应讲义　④

易错上下两半用同一套公式，下半 i 倒着走。

#include <stdio.h>

void diamond(int n)
{
    int i, j;
    for (i = 1; i <= n; i++) {
        for (j = 1; j <= n - i; j++) printf(" ");
        for (j = 1; j <= 2 * i - 1; j++) printf("*");
        printf("\n");
    }
    for (i = n - 1; i >= 1; i--) {
        for (j = 1; j <= n - i; j++) printf(" ");
        for (j = 1; j <= 2 * i - 1; j++) printf("*");
        printf("\n");
    }
}

int main(void)
{
    diamond(4);
    return 0;
}

运行结果

   *
  ***
 *****
*******
 *****
  ***
   *

题4错位星号

综合 · 教材第6章习题11

输出以下图案：

* * * * *
  * * * * *
    * * * * *
      * * * * *
        * * * * *

（5 行，每行 5 个星号，星号之间一个空格；每下一行整体右移 2 格）

要求

slanted(rows) 打印 rows 行这样的图案。每行：前面 2*i 个空格（i 从 0 数），然后 "* * * * *"（最后一个星号后面没有空格），然后换行。

对应讲义　⑤

易错每行右移 2 格；最后一个星号后面不加空格。

#include <stdio.h>

void slanted(int rows)
{
    int i, j;
    for (i = 0; i < rows; i++) {
        for (j = 0; j < 2 * i; j++) printf(" ");
        for (j = 1; j <= 5; j++) {
            printf("*");
            if (j < 5) printf(" ");
        }
        printf("\n");
    }
}

int main(void)
{
    slanted(5);
    return 0;
}

运行结果

* * * * *
  * * * * *
    * * * * *
      * * * * *
        * * * * *

题5杨辉三角

限时 · 2024 第2题（学长说这题 15 分） · 限时 15 分钟

打印杨辉三角。

要求

yanghui(n) 打印前 n 行（n <= 10）。每行的数之间一个空格，行首不加空格，行尾不加空格。

例如 n=4：

1
1 1
1 2 1
1 3 3 1
  • 思路二维数组 a[10][10]；每行两端是 1；中间 a[i][j] = a[i-1][j-1] + a[i-1][j]。

对应讲义　⑥

易错两端先置 1；中间 j 从 1 到 i-1；数之间才加空格。

#include <stdio.h>

void yanghui(int n)
{
    int a[10][10], i, j;
    for (i = 0; i < n; i++) {
        a[i][0] = a[i][i] = 1;
        for (j = 1; j < i; j++)
            a[i][j] = a[i - 1][j - 1] + a[i - 1][j];
    }
    for (i = 0; i < n; i++) {
        for (j = 0; j <= i; j++) {
            if (j > 0) printf(" ");
            printf("%d", a[i][j]);
        }
        printf("\n");
    }
}

int main(void)
{
    int n;
    scanf("%d", &n);
    yanghui(n);
    return 0;
}

输入

6

运行结果

1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
1 5 10 10 5 1

开始之前，先回想一下

编程题怎么写

外层一轮 = 一行。每一行：先打空格，再打字符，最后换行。

通用骨架

for (i = 1; i <= n; i++) {                            // 第 i 行
    for (j = 1; j <= 空格数(i); j++) printf(" ");
    for (j = 1; j <= 字符数(i); j++) printf("*");
    printf("\n");                                     // 换行在内层循环外面
}

①先在纸上列表，再找公式

n = 4 的金字塔，一行一行数：

第 i 行空格星号
131
223
315
407

看出来：空格 = n − i，星号 = 2i − 1。把这两个公式填进骨架的两个内层上界，就写完了：

   *
  ***
 *****
*******

所有图案题都先做这一步，公式找对了，代码几乎不会错。

②内层的上界要跟着 i 变

内层上界写成常数，每行打的个数都一样，图案就成了矩形：

for (i = 1; i <= 3; i++) {
    for (j = 1; j <= 5; j++) printf("*");     // 上界是常数 5
    printf("\n");
}
*****
*****
*****

三角形的每行个数不一样，所以上界里一定有 i。

③换行放在内层循环外面

printf("\n") 要在内层循环外面、外层循环里面。放进内层，就成了一个星号一行：

for (i = 1; i <= 2; i++)
    for (j = 1; j <= 3; j++) { printf("*"); printf("\n"); }

这段输出 6 行，每行一个 *。

④菱形：上半正着走，下半倒着走

菱形的下半就是上半倒过来。公式不用改，只要让 i 倒着走：

for (i = 1; i <= n; i++)      { 空格 n-i 个；星号 2i-1 个；换行 }   // 上半
for (i = n - 1; i >= 1; i--)  { 空格 n-i 个；星号 2i-1 个；换行 }   // 下半

n = 3：

  *
 ***
*****
 ***
  *

下半从 n − 1 开始，不然中间最宽的那行会打两遍。

⑤星号之间有空格

图案里写成「* * * *」时，一个单位是「星号 + 空格」两格宽。行尾不想多一个空格，就在最后一个之前才打空格：

for (j = 1; j <= 4; j++) {
    printf("*");
    if (j < 4) printf(" ");     // 最后一个星号后面不加空格
}

每行再错开几格，就是在前面多打几个空格：第 i 行（i 从 0 数）先打 i 个空格。三行的样子：

* * * *
 * * * *
  * * * *

⑥杨辉三角：两边是 1，中间是左上加正上

用二维数组存（二维数组的规矩环07 细讲）：

for (i = 0; i < n; i++) {
    a[i][0] = a[i][i] = 1;                            // 每行两端
    for (j = 1; j < i; j++)
        a[i][j] = a[i - 1][j - 1] + a[i - 1][j];      // 左上 + 正上
}
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
1 5 10 10 5 1

第 i 行只用 a[i][0] 到 a[i][i]。数和数之间一个空格、行首行尾不加，可以用 printf(k ? " %d" : "%d", a[i][k])（环03 细7 的条件运算符）。

⑦数字表格：给宽度就对齐了

九九乘法表这类，给每个数一个固定宽度。%-3d 占 3 格、靠左（环01 细10）：

for (i = 1; i <= 3; i++) {
    for (j = 1; j <= i; j++) printf("%d*%d=%-3d", j, i, i * j);
    printf("\n");
}
1*1=1
1*2=2  2*2=4
1*3=3  2*3=6  3*3=9

⑧写完用 n = 1 测一次

写之前画 n = 3 的样子数格子；写完拿 n = 1 测：金字塔应该只有一个 *，菱形也只有一个 *。最容易错的就是这个边界。

输出和循环变量的坑

每一节最后附了真题的问法，灰色小字是出处。

细1putchar、puts、printf

  • putchar(c)：输出一个字符。putchar(65) 输出 A，putchar('0' + 5) 输出 5。
  • puts(s)：输出一个字符串，自动加换行。
  • printf：最灵活，但不会自动换行。

putchar("A") 错，要的是字符不是字符串；putchar('ab') 里的 'ab' 本身就不合法（环02 细3）。

真题里这样考

能输出字符 a 的 → putchar(97)配-3-62

for (i = 0; i < 5; i++) putchar('Z' - i); → ZYXWV配-3-64

细2%5d、%-5s：宽度和对齐

环01 细10 讲过数字，字符串和字符也一样。下面用 · 表示空格：

printf("%5d", 42)→···42 printf("%-5d", 42)→42··· printf("%5s", "ab")→···ab printf("%-5s", "ab")→ab··· printf("%3c", 'x')→··x printf("%2d", 12345)→12345 比宽度长，原样输出，不截断

真题里这样考

printf("%4d,%o,%x", 10, 10, 10); → ··10,12,a配-3-6

细3每行输出 k 个就换行

用下标或计数器取余：

for (i = 0; i < 10; i++) {
    printf("%3d", i);
    if ((i + 1) % 4 == 0) printf("\n");     // 第 4、8 个后面换行
}

第二行是 4 5 6 7，第三行只有 8 9。

(i + 1) % 4 和 i % 4 差在哪：前者是「打完第 4 个之后换行」，后者是「打第 0、4、8 个之前换行」，所以要写在 printf 前面。

真题里这样考

每行 8 个的填空 → if (i % 8 == 0) printf("\n");（写在 printf 之前）配-4-34

细4内外层用了同一个循环变量

cnt = 0;
for (i = 1; i <= 3; i++)
    for (i = 1; i <= 2; i++) cnt++;     // 内层也用 i

想要 3 × 2 = 6 次，实际 2 次：内层结束时 i 是 3，外层 i++ 变成 4，外层立刻结束。

图案题内层一律用 j。

细5循环体里又改了循环变量

读程序时，每一处 k++、++k 都要算进去，一轮里 k 可能被加好几次：

for (k = 1; k <= 40; k++) {
    if (k++ % 5 == 0)
        if (++k % 8 == 0) printf("%d ", k);
}

输出 32。追踪时把「判断前的 k、判断后的 k、这一轮结束的 k」分三列写。

细7嵌套循环执行几次

外层 m 次、内层 n 次，内层语句执行 m × n 次。有 continue 跳过的要减掉：

cnt = 0;
for (i = 0; i < 2; i++)
    for (j = 0; j <= 3; j++) { if (j % 2 == 0) continue; cnt++; }

内层 j 取 0、1、2、3，只有 1、3 会数，所以 cnt = 4。

嵌套循环后 x 的最终值配-5-52

细8行尾空格、换行：要有数格子的习惯

考试手写，行尾多一个空格、少一个换行一般不扣分；但这个仓库的测试是逐字比较的，所以题目会把格式写清楚。写图案题时养成习惯：每一行先数清楚有几个空格、几个字符。

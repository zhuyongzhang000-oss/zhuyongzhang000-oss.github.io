题1e 的级数

代表题 · 2012 第1题

计算 e = 1 + 1/1! + 1/2! + ... + 1/n! 的值并输出（设 n=15）。

要求

e_series(n) 返回 1 + 1/1! + ... + 1/n!（n=0 时就是 1）。

对应讲义　① ③ ④

易错不要真的算阶乘（int 到 13! 就溢出），用 t = t/i 递推。

#include <stdio.h>

double e_series(int n)
{
    double s = 1, t = 1;    /* 第 0 项是 1 */
    int i;
    for (i = 1; i <= n; i++) {
        t = t / i;          /* t 从 1/(i-1)! 变成 1/i! */
        s += t;
    }
    return s;
}

int main(void)
{
    printf("e = %f\n", e_series(15));
    return 0;
}

运行结果

e = 2.718282

题2a 加 aa

变式 · 2013 第2题

求 s = a + aa + aaa + ... + aa…a（共 n 个 a），a 是一个数字，a 和 n 由键盘输入。例如 a=3,n=5 时 s=3+33+333+3333+33333。

要求

repeat_sum(a, n) 返回 s。

  • 和题1 的关系骨架一样（累加 + 用上一项推下一项），只是"下一项"换了。

易错下一项 = 上一项*10 + a；结果用 long long。

#include <stdio.h>

long long repeat_sum(int a, int n)
{
    long long s = 0, t = 0;
    int i;
    for (i = 1; i <= n; i++) {
        t = t * 10 + a;     /* 3 -> 33 -> 333 */
        s += t;
    }
    return s;
}

int main(void)
{
    int a, n;
    scanf("%d%d", &a, &n);
    printf("s = %lld\n", repeat_sum(a, n));
    return 0;
}

输入

3 5

运行结果

s = 37035

题3分数序列

变式 · 2017 第3题

计算 2/1 + 3/2 + 5/3 + 8/5 + 13/8 + 21/13 + ... 前 20 项之和并输出。

要求

frac_sum(n) 返回前 n 项之和（考试 n=20）。

  • 规律下一项分子 = 分子+分母，下一项分母 = 原来的分子。

对应讲义　① ⑤

易错分子分母同时更新要先存旧值；除法前转 double。

#include <stdio.h>

double frac_sum(int n)
{
    double s = 0;
    long long a = 2, b = 1, old;   /* 分子 a，分母 b */
    int i;
    for (i = 1; i <= n; i++) {
        s += (double)a / b;
        old = a;
        a = a + b;
        b = old;
    }
    return s;
}

int main(void)
{
    printf("前 20 项之和 = %f\n", frac_sum(20));
    return 0;
}

运行结果

前 20 项之和 = 32.660261

题4cos 级数

综合 · 2018 第3题

计算 cos(x) ≈ 1 - x²/2! + x⁴/4! - x⁶/6! + ...，要求最后一项的绝对值小于 1e-5 为止。

要求

cos_series(x) 返回近似值（不能调用库函数 cos）。

  • 这是"精度型"不知道循环几次，用 while 判断项的大小。

对应讲义　④ ⑥

易错项要 fabs 再比较；相邻两项比是 -x*x/((2n-1)*(2n))。

#include <stdio.h>
#include <math.h>

double cos_series(double x)
{
    double s = 0, t = 1;     /* 第一项 1 */
    int n = 0;
    while (fabs(t) >= 1e-5) {
        s += t;
        n++;
        t = -t * x * x / ((2 * n - 1) * (2 * n));
    }
    return s;
}

int main(void)
{
    double x;
    scanf("%lf", &x);
    printf("cos(%g) = %f\n", x, cos_series(x));
    return 0;
}

输入

1.0

运行结果

cos(1) = 0.540303

题5当年第几天

综合 · 2018 第2题

对给定的某年某月某日，计算并输出它是这一年的第几天。日期从键盘输入。

要求

day_of_year(y, m, d) 返回第几天（输入保证合法）。

  • 思路前 m-1 个月的天数加起来，再加 d；闰年 2 月多 1 天。

对应讲义　⑦

易错只加前 m-1 个月；闰年条件三段写全。

#include <stdio.h>

int day_of_year(int y, int m, int d)
{
    int days[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
    int leap = (y % 4 == 0 && y % 100 != 0) || y % 400 == 0;
    int i, sum = d;
    for (i = 1; i < m; i++)
        sum += days[i];
    if (m > 2 && leap)
        sum += 1;
    return sum;
}

int main(void)
{
    int y, m, d;
    scanf("%d%d%d", &y, &m, &d);
    printf("是这一年的第 %d 天\n", day_of_year(y, m, d));
    return 0;
}

输入

2024 3 1

运行结果

是这一年的第 61 天

编程题怎么写

这一环 5 道题，长得不一样，骨架是同一个：

通用骨架

double s = 0;               // 和从 0 开始（求积就从 1 开始）
double t = 第一项;
for (i = 1; i <= n; i++) {
    s += t;
    t = 下一项;              // 用这一项算出下一项
}

题目没说算几项、只说「直到某一项的绝对值小于 1e-5」，就把 for 换成 while：

while (fabs(t) >= 1e-5) {
    s += t;
    t = 下一项;
}

①1 / 2 等于 0

先看一段想算 e 的代码：

double e = 1;
for (i = 1; i <= 5; i++)
    e += 1 / i;

e 最后是 2.0，离 2.718 差得远。

原因：1 / i 两边都是整数，C 就做整数除法，小数部分直接扔掉。i = 1 时得 1，之后 1/2、1/3… 全是 0。e 是 double 也没用，因为除法在赋值之前就已经算完了。

1 / 2→0 1.0 / 2→0.5 (double)1 / 2→0.5 先把 1 变成 1.0，再除 (double)(1 / 2)→0.0 括号里已经整除成 0 了，再转也晚了

改法：写 1.0 / i。只要有一边是小数，就按小数除。

这一条是全书出现次数最多的坑，后面求平均分、算比例、算面积都会再碰到。

②和从 0 开始，积从 1 开始

积的初值写成 0，乘多少次都是 0。这个错不报错，只会让答案莫名其妙变成 0。

另一个坑是干脆不写初值：函数里定义的 int s; 不会自动是 0，里面是一个不确定的数（配-2-51 就考这个）。累加之前一定先 s = 0。

③int 只装得下 21 亿

int 最大是 2147483647。12! = 479001600 还装得下，13! = 6227020800 就超了。超了不会报错，只会得到一个错的数。

题2 也会遇到：a = 3、n = 10 时最后一项是 3333333333，约 33 亿，int 同样装不下。测试里就有 n = 10。

办法是换大一点的类型：long long（printf 用 %lld），或者 double。

④用上一项推下一项

e 的级数第 i 项是 1/i!。笨办法是每一项都重新算一遍阶乘；更好的办法是注意到第 i 项 = 第 i−1 项 ÷ i，于是每轮只做一次除法：

t = 1;  e = 1;
for (i = 1; i <= n; i++) {
    t = t / i;      // 1/(i-1)!  变成  1/i!
    e += t;
}

别的数列也是同一招：把第 i 项和第 i−1 项写在一起，看差了什么。比如

  • x, x²/2!, x³/3!, …：下一项是 t = t * x / i;
  • 1, −1/2, 1/3, −1/4, …：多一个符号变量，每轮 sign = -sign;

题2（3, 33, 333…）和题4（cos 级数）的下一项留给你自己推。题4 提示：相邻两项差一个负号，还差一个 x²，分母多乘了两个数。

⑤两个量一起变，先存旧值

题3 的数列 2/1, 3/2, 5/3, 8/5…，规律是：新分子 = 分子 + 分母，新分母 = 原来的分子。很自然会写成左边这样：

直接写
a = a + b;
b = a;
先存旧值
old = a;
a = a + b;
b = old;

从 2/1 开始各走三轮。左边：3/3 → 6/6 → 12/12；右边：3/2 → 5/3 → 8/5。

左边错在第二句：b = a 用的是第一句改过以后的 a。两个量互相要用对方的旧值时，先把旧值存起来。

还有一处：算 a/b 这一项时，a、b 是整数，要写 (double)a / b，不然又回到第 ① 节。

⑥小数的绝对值用 fabs

精度型循环的条件是 fabs(t) >= 1e-5，意思是「这一项还不够小，就继续加」。1e-5 就是 0.00001。

两个容易错的地方：

  • 用了 abs。abs 是给整数用的，abs(-0.001) 得 0，循环一开始就停了。fabs 在 <math.h> 里。
  • 忘了取绝对值，写成 while (t >= 1e-5)。cos 级数第二项就是负的，循环会提前停。

按这个写法，小于 1e-5 的那一项不会加进去，正好符合「末项绝对值小于 1e-5 为止」。

⑦闰年和每月天数

闰年：能被 4 整除但不能被 100 整除，或者能被 400 整除。写成代码：

int leap = (y % 4 == 0 && y % 100 != 0) || y % 400 == 0;

试一下：2000 年 是，1900 年 不是，2024 年 是，2023 年 不是。1900 最容易错：它能被 4 整除，但也能被 100 整除，又不能被 400 整除。

每月天数放进数组，下标 0 空着放个 0，这样 days[3] 就是 3 月，不用减 1：

int days[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

闰年的 2 月是 days[2] + leap。

⑧考试要写完整程序

电脑上每题只写一个函数，考试却是手写整个程序。拿一道不是本环必做的题举例，求 1 + 1/2 + … + 1/n：

#include <stdio.h>

int main(void)
{
    int n, i;
    double s = 0;

    scanf("%d", &n);           // 变量前面有 &
    for (i = 1; i <= n; i++)
        s += 1.0 / i;
    printf("%f\n", s);

}

格式符最容易混的是 double：输入必须 %lf，输出 %f 和 %lf 都行。long long 输入输出都是 %lld。

教材常写 void main()，考试不扣分；平时按标准写 int main(void) 加 return 0;。

细20 开头的数是八进制

这是最阴的一个：011 不是 11，而是八进制的 11，等于 9。0x 开头是十六进制，0x13 等于 19。

既然 0 开头是八进制，八进制里又只有 0–7，那么 08、0118、-028 都不合法。

还有几个常见的假常量：1,234（数里不能有逗号），o115（字母 o 开头，是个名字），0b101（二进制写法 C23 才有，考试按「不能写」）。115L 是合法的 long 型常量。

细3小数常量：e 两边的规矩

小数点两边可以省一边，.5 和 3. 都对。

科学计数法只记一句：e 前面必须有数字，e 后面必须是整数（可以带负号）。所以 1e1、.1e0、2.E8、1.5e-3 都合法；1.5E2.0 和 4e1.5 不行（e 后是小数），e3 不行（前面没数，成了一个名字），2.7e 不行（后面没数）。

小数常量默认是 double；写成 1.5f 才是 float。

细8i++ 和 ++i

两个都会让 i 加 1。区别在于这个式子交出来的值：i++ 交出加之前的 i，++i 交出加之后的 i。

依次执行：

i = 5; a = i++;→a = 5，i = 6 b = ++i;→i = 7，b = 7 i = 3; a = -i++;→a = -3，i = 4 就是 −(i++)

单独一句 i++; 和 ++i; 没区别。只能对变量用：5++、(j + 1)++ 编译不过。

细9逗号表达式

逗号把几个式子串起来，从左到右都执行，整个式子的值是最后一个。

考点在于 = 比逗号先算。看这句：

x = y = 1;
z = x++, y++, ++y;

它其实是 (z = x++), y++, ++y;。所以 x = 2，y = 3，z = 1。

想让 z 拿到整个逗号式子的值，必须加括号：z = (x = 10, x + 5); 得 z = 15。

细10printf 的宽度和小数位

%5d 占 5 格、靠右；%-5d 靠左；%05d 左边补 0；%.2f 保留 2 位（四舍五入）；%8.3f 一共占 8 格，小数点也算一格。数比宽度长，就原样全部输出。%f 不写位数默认 6 位小数。

下面用 · 表示空格：

printf("%5d", 42)→···42 printf("%-5d", 42)→42··· printf("%05d", 42)→00042 printf("%8.3f", 3.14159)→···3.142 printf("%e", 123.456)→1.234560e+02 printf("%%")→% 两个 % 打出一个

真题里这样考

printf("%d%8.6f", 12, 3.141593); → 123.141593（宽 8 刚好装下，中间没空格）配-3-10

printf("%4d,%o,%x", 10, 10, 10); → ··10,12,a配-3-6

printf("a=%%d,b=%%d", a, c); → a=%d,b=%d配-3-11

x = 2.12，哪种格式输出不完整 → %5.0f（只剩 2）配-3-5

细11scanf：格式里写什么，就得敲什么

scanf 的格式串是一张「输入模板」。除了 %d 这些，里面写的其他字符都要原样敲进去：

scanf("%d%d", &a, &b);敲3 4（空格、回车都行） scanf("%d,%d", &a, &b);敲3,4（逗号必须敲） scanf("a=%d", &a);敲a=3

宽度会截断：scanf("%2d%f", &a, &b); 输入 876 543.0，a 只读两位得 87，剩下的 6 给了 b，b = 6.0。

三个硬规矩：

  • 变量前加 &，数组名不加。scanf("%d", a); 常常能编译，运行时把数写到乱地址。
  • double 输入必须 %lf，float 用 %f。
  • 格式里不能写精度，scanf("%3.2f", &x); 是错的。

细12一个变量在一句里被改两次

像 i = i++ + 1;、a += a -= a * a;、printf("%d %d", i, i++); 这样，同一个变量在一句里被改了两次，C 标准没有规定结果（叫未定义行为），换个编译器结果就可能不一样。自己写程序绝对不要这样写。

但题库和期末卷还是会出，并且按「从右往左一步一步赋值」给答案。考试遇到就按这个思路算：

真题里这样考

a = 12; a += a -= a * a; 之后 a → -264配-2-104

a = 3; a += a -= a * a; 之后 a → -12川师卷2019-20 一-8

算法：先算右边的 a -= a * a，a = 3 − 9 = −6；再算 a += a，−6 + (−6) = −12。

细13一个 C 程序长什么样

教材第 1 章的选择题，围绕下面这几句话出：

  • C 程序由函数组成，有且只有一个 main，程序从 main 开始执行，main 写在文件哪里都行。
  • #include、#define 这种 # 开头的是预处理命令，在编译之前处理，末尾不加分号。
  • 每条语句以分号结束，一行可以写好几条，一条也可以分几行写。
  • 注释 /* … */ 和 // 不参与编译；/* */ 不能嵌套。
  • C 语言本身没有输入输出语句，printf、scanf 是库函数。

判断一下：

main 必须写在程序最前面错 位置随意，总是从 main 开始执行 #include <stdio.h>;错 预处理命令末尾不加分号 printf 是 C 的关键字错 是库函数，在 stdio.h 里声明 一行只能写一条语句错

从源程序到运行要经过：编辑（.c）→ 编译（得到 .obj）→ 链接（得到 .exe）→ 运行。漏分号、括号不配对是编译时发现的；调用了只声明没写的函数，链接时报错；能运行但结果不对是逻辑错误，只能靠测试发现。

细14算法的五个特性和三种结构

教材第 2 章考的是概念，记住这两组就够：

五个特性：有穷性（步数有限，不能死循环）、确定性（每一步没有歧义）、有零个或多个输入、有一个或多个输出、有效性（每一步都能做到）。

最常考的是输入输出那两条：算法可以没有输入，但必须有输出。

三种基本结构：顺序、选择、循环。循环分当型（先判断再做，对应 while）和直到型（先做再判断，对应 do-while）。三种结构都是一个入口、一个出口。

表示方法：自然语言、流程图（起止框是圆角矩形、判断框是菱形、输入输出框是平行四边形、处理框是矩形）、N-S 图、伪代码、程序语言。

结构化程序设计的方法：自顶向下、逐步细化、模块化设计、结构化编码。

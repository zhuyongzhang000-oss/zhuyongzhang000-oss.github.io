题1大数阶乘

必做 · 2016 第4题的延伸

求 n! 的精确值（0 <= n <= 100，100! 有 158 位）。

要求

big_fact(n, out)：把 n! 的十进制写成字符串放进 out（不能有前导 0），返回位数。

例如 big_fact(25, out) 得 "15511210043330985984000000"，返回 26。

  • 依据2016④「输入整数 n，计算 n 的阶乘并输出，要求使用双精度型」（15 分）；学长清单「阶乘」「双精度」。double 只有 15~16 位有效数字，20! 以后打印出来的末几位就不准了；要精确值只能用数组一位一位存。
  • 思路int d[200]，d[0] 是个位，len 是当前位数，开始 d[0] = 1、len = 1。乘以 i：每一位 d[k] = d[k] × i + 进位，留下 % 10，进位是 / 10；最后进位不为 0 就继续往高位放。输出时从最高位往个位写，每位 + '0'，最后补 '\0'。

对应讲义　① ②

易错d[0] 是个位；进位要一直放到 0 为止；输出从最高位倒着写，补 '\0'。

#include <stdio.h>

int big_fact(int n, char *out)
{
    int d[200], len = 1, i, k, carry, t;
    d[0] = 1;
    for (i = 2; i <= n; i++) {
        carry = 0;
        for (k = 0; k < len; k++) {
            t = d[k] * i + carry;
            d[k] = t % 10;
            carry = t / 10;
        }
        while (carry > 0) {                         /* 进位可能不止一位 */
            d[len++] = carry % 10;
            carry /= 10;
        }
    }
    for (k = 0; k < len; k++) out[k] = (char)('0' + d[len - 1 - k]);
    out[len] = '\0';
    return len;
}

int main(void)
{
    char s[200];
    int n, len;
    double d = 1;
    int i;
    scanf("%d", &n);
    len = big_fact(n, s);
    for (i = 2; i <= n; i++) d *= i;         /* 原题的双精度做法，对比一下 */
    printf("%d! = %s（%d 位）\n", n, s, len);
    printf("double 算的：%.0f\n", d);
    return 0;
}

输入

25

运行结果

25! = 15511210043330985984000000（26 位）
double 算的：15511210043330986055303168

题2标准差

必做 · 2024 第4题

用代码实现标准差计算：σ = √( (1/N) × Σ(xi − μ)² )，μ 是平均值。

要求

两个函数。

(1) stddev(x, n, sample)：sample 是 0 时按原题除以 N（总体标准差）；sample 是 1 时除以 N − 1（样本标准差）。

sample 是 1 而 n < 2 时返回 0。

(2) outliers(x, n, k, idx)：把满足 |x[i] − μ| > k × σ（σ 用总体标准差）的下标 i 从小到大放进 idx，返回个数。

  • 依据2024④「用代码实现标准差计算 σ = sqrt( (1/N) Σ (xi − μ)² )」；学长「浮点类型要注意」。
  • 思路两遍扫描：第一遍求和得 μ，第二遍累加 (x[i] − μ)²。除法前想清楚分母是 n 还是 n − 1（int 和 double 混算没问题，但 1 / n 这种两个整数相除就是 0）。绝对值用 fabs，开方用 sqrt，都在 math.h。

对应讲义　③

易错两遍扫描；分母 n 还是 n-1；n < 2 的样本标准差单独处理；绝对值用 fabs。

#include <stdio.h>
#include <math.h>

static double mean(const double x[], int n)
{
    double s = 0;
    int i;
    for (i = 0; i < n; i++) s += x[i];
    return s / n;
}

double stddev(const double x[], int n, int sample)
{
    double mu, s = 0;
    int i;
    if (sample && n < 2) return 0;
    mu = mean(x, n);
    for (i = 0; i < n; i++) s += (x[i] - mu) * (x[i] - mu);
    return sqrt(s / (sample ? n - 1 : n));
}

int outliers(const double x[], int n, double k, int idx[])
{
    double mu = mean(x, n), sd = stddev(x, n, 0);
    int i, c = 0;
    for (i = 0; i < n; i++)
        if (fabs(x[i] - mu) > k * sd) idx[c++] = i;
    return c;
}

int main(void)
{
    double x[100];
    int n, i, idx[100], k;
    scanf("%d", &n);
    for (i = 0; i < n; i++) scanf("%lf", &x[i]);
    printf("总体标准差 %.4f，样本标准差 %.4f\n", stddev(x, n, 0), stddev(x, n, 1));
    k = outliers(x, n, 1.5, idx);
    printf("偏离平均值超过 1.5 倍标准差的有 %d 个：", k);
    for (i = 0; i < k; i++) printf("x[%d]=%g ", idx[i], x[idx[i]]);
    printf("\n");
    return 0;
}

输入

5
10 12 11 13 50

运行结果

总体标准差 15.4324，样本标准差 17.2540
偏离平均值超过 1.5 倍标准差的有 1 个：x[4]=50

题3方程求根

必做 · 数学模拟 + 函数指针

用两种方法求方程 f(x) = 0 的根，方程通过函数指针传进来。

要求

两个函数。

(1) bisect(f, a, b, eps)：二分法。保证 f(a)、f(b) 异号或者有一个是 0。f(a) 是 0 返回 a，f(b) 是 0 返回 b；否则每次取中点 m，保留异号的那一半，区间长度 b − a < eps 时停，返回最后区间的中点。

(2) newton(f, df, x0, eps, &iters)：牛顿迭代 x1 = x0 − f(x0) / df(x0)（df 是导数）。

每算出一个新的 x 就计一次数；|x1 − x0| < eps 时停，返回 x1，算了几次用 iters 带回。

例如 f(x) = x² − 2，df(x) = 2x，x0 = 1，eps = 1e-10：算 5 次，返回 1.41421356…

  • 依据学长「很爱考数学的东西」；教材第 7 章习题「用牛顿迭代法求方程的根」；教材 8.5 函数指针作参数。
  • 思路(1) 判断异号写 f(a) * f(m) < 0，或者分别看正负（乘起来可能下溢成 0，看正负更稳）。(2) do-while 最自然：先算新的，再判断要不要继续。

对应讲义　④ ⑤

易错端点是根要先判断；保留「异号」的那一半；牛顿迭代先算新值再判断，计数和返回值对应。

#include <stdio.h>
#include <math.h>

double bisect(double (*f)(double), double a, double b, double eps)
{
    double m, fa = f(a), fm;
    if (fa == 0) return a;
    if (f(b) == 0) return b;
    while (b - a >= eps) {
        m = (a + b) / 2;
        fm = f(m);
        if (fm == 0) return m;
        if ((fa < 0) != (fm < 0)) b = m;            /* 根在左半边 */
        else { a = m; fa = fm; }                    /* 根在右半边 */
    }
    return (a + b) / 2;
}

double newton(double (*f)(double), double (*df)(double), double x0, double eps, int *iters)
{
    double x1;
    int k = 0;
    do {
        x1 = x0 - f(x0) / df(x0);
        k++;
        if (fabs(x1 - x0) < eps) break;
        x0 = x1;
    } while (1);
    *iters = k;
    return x1;
}

double f(double x) { return x * x * x - x - 1; }
double df(double x) { return 3 * x * x - 1; }

int main(void)
{
    int it;
    double r;
    printf("二分法：%.10f\n", bisect(f, 1, 2, 1e-10));
    r = newton(f, df, 1.5, 1e-12, &it);
    printf("牛顿法：%.10f（迭代 %d 次）\n", r, it);
    return 0;
}

运行结果

二分法：1.3247179573
牛顿法：1.3247179572（迭代 5 次）

题4分数精确求和

选做 · 2017 第3题用分数精确算

分数用两个 long long（分子 num、分母 den）表示，始终保持最简、分母为正。

要求

两个函数。

(1) frac_add(&num, &den, a, b)：把 a/b 加到 num/den 上，结果约成最简（b > 0）。

(2) fib_frac_sum(n, &num, &den)：求 2/1 + 3/2 + 5/3 + …… 前 n 项的和（最简分数），n <= 15。

例如 n = 3：2/1 + 3/2 + 5/3 = 31/6。

（到第 20 项分母有 28 位，long long 装不下——这正是原题用 double 的原因。）

  • 依据2017③「计算并输出 sum = 2/1 + 3/2 + 5/3 + 8/5 + 13/8 + 21/13 + …… 前 20 项之和」（15 分）；学长「浮点类型要注意」。原题用 double 算就对了；这里练「不用浮点、用分数算出精确值」。
  • 思路(1) 通分前先约：g = gcd(den, b)，新分母 = den / g × b，新分子 = num × (b / g) + a × (den / g)，再除以 gcd(新分子, 新分母)。先约再乘，中间结果小，不容易溢出。gcd 用辗转相除（环03）。(2) 分子分母都是 Fibonacci 数：每项的分母是上一项的分子。

对应讲义　⑥

易错先用 gcd(den, b) 约再相乘，避免溢出；结果再约一次；每项分母是上一项的分子。

#include <stdio.h>

static long long gcd(long long a, long long b)
{
    long long t;
    if (a < 0) a = -a;
    while (b != 0) { t = a % b; a = b; b = t; }
    return a;
}

void frac_add(long long *num, long long *den, long long a, long long b)
{
    long long g = gcd(*den, b), n, d;
    d = *den / g * b;
    n = *num * (b / g) + a * (*den / g);
    g = gcd(n, d);
    if (g == 0) g = 1;
    *num = n / g;
    *den = d / g;
}

void fib_frac_sum(int n, long long *num, long long *den)
{
    long long p = 1, q = 2, t;                      /* 第 1 项是 q/p = 2/1 */
    int i;
    *num = 0;
    *den = 1;
    for (i = 1; i <= n; i++) {
        frac_add(num, den, q, p);
        t = p + q;                                  /* 下一项：分母是这一项的分子 */
        p = q;
        q = t;
    }
}

int main(void)
{
    long long num, den;
    int n;
    scanf("%d", &n);
    fib_frac_sum(n, &num, &den);
    printf("前 %d 项之和 = %lld/%lld ≈ %.6f\n", n, num, den, (double)num / den);
    return 0;
}

输入

10

运行结果

前 10 项之和 = 998361233/60580520 ≈ 16.479905

开始之前，先回想一下

这些是前面学过、这一环又要用到的基础。想不起来就回到出处那一节再看一眼。

1 / 2 的值 → 0（两个整数相除，小数直接扔掉）环01 ①

int 最大大约是 → 21 亿（2^31 − 1），13! 就超了环01 ③

小数取绝对值用 → fabs，不是 abs环01 ⑥

两个小数比相等 → 不要用 ==，看差的绝对值是否小于一个很小的数环03 细10

辗转相除求最大公约数 → while (b != 0) { t = a % b; a = b; b = t; }环03 ⑥

套路

先选对类型，再写循环。

①先估算：结果有多大，选什么类型

类型范围 / 精度阶乘能精确算到
int约 ±21 亿12!
long long约 ±9.2 × 10^1820!
double约 10^308，但只有 15～16 位有效数字22!（23! 起末几位不准）
float只有 6～7 位有效数字别用
int 算 13!→超出范围，结果不可靠 常见打印 1932053504 double 算 23!，printf("%.0f")→25852016738884978212864 真值 25852016738884976640000

2016④ 要求「使用双精度型」，就是为了让 n 大一点也能算——但双精度只是不溢出，不保证每一位都准。要精确，就用 ② 的数组。

②大数：数组每格存一位，模拟竖式乘法

d[0] 是个位，len 是位数。乘以 i：

carry = 0;
for (k = 0; k < len; k++) {
    t = d[k] * i + carry;
    d[k] = t % 10;          // 这一位留下个位
    carry = t / 10;         // 其余进到高一位
}
while (carry > 0) {         // 最高位还有进位：位数变多
    d[len++] = carry % 10;
    carry /= 10;
}

输出从 d[len − 1] 往 d[0]。进位 carry 可能是好几位（乘 100 时），所以最后是 while 不是 if。

同一套写法还能做：2 的 100 次方、大数加法、1! + 2! + … + 30!。

③标准差：先算平均值，再算偏差平方和

for (i = 0; i < n; i++) s += x[i];
mu = s / n;                                   // 第一遍：平均值
for (i = 0; i < n; i++) s2 += (x[i] - mu) * (x[i] - mu);
sigma = sqrt(s2 / n);                         // 第二遍：总体标准差
总体标准差（2024④ 原题）→除以 N 样本标准差→除以 N − 1 N = 1 时分母是 0，要单独处理 2 4 4 4 5 5 7 9 的总体标准差→2
  • 数据是 int 时，s / n 两个都是整数就丢了小数。累加变量用 double，或者写 (double)s / n。
  • 「一遍扫描」公式 σ² = 平方的平均 − 平均的平方，数学上对，但两个大数相减会丢精度，甚至算出很小的负数，sqrt 得到 nan。考试用两遍。

④精度控制：什么时候停

两类停止条件，读题时先分清：

「最后一项的绝对值小于 1e-6」→项小于 eps 时停，这一项加不加看题意 cos、e 的级数（环01） 「两次结果之差小于 eps」→迭代：新旧两个值比 牛顿迭代 「区间长度小于 eps」→二分法

二分法：保持「f 在两个端点异号」，每次取中点，留下异号的那一半。

while (b - a >= eps) {
    m = (a + b) / 2;
    if ((f(a) < 0) != (f(m) < 0)) b = m;   // 异号：根在 [a, m]
    else a = m;                            // 否则在 [m, b]
}

判断异号写 f(a) * f(m) < 0 也行，但两个很小的数相乘可能变成 0。不要假设 f(a) 一定是负的：2 − x² 在 [0, 2] 上 f(a) 是正的。

⑤牛顿迭代：do-while，先算再判断

do {
    x1 = x0 - f(x0) / df(x0);
    k++;
    if (fabs(x1 - x0) < eps) break;
    x0 = x1;
} while (1);

方程用函数指针传进来（拔04 ④）：double (*f)(double)，调用写 f(x0)。同一个求根函数，传不同的 f 就能解不同的方程——教材 8.5 节求定积分也是这个写法。

x² − 2 = 0 从 1 开始：1 → 1.5 → 1.41667 → 1.414216 → …，第 5 次时和上一次差小于 1e-10。

⑥浮点陷阱，和学长清单上的小题

0.1 + 0.2 == 0.3→0（假） 用 fabs(a − b) < 1e-9 float 加 10 次 0.1f 等于 1.0f 吗→不等，得 1.00000012 (int)(0.29 * 100)→28 0.29 × 100 实际是 28.999…，强转直接截断 scanf 读 double→%lf printf 输出 double 用 %f、%lf 都行

分数精确算：分子分母两个整数，每次相加先通分、再用 gcd 约分。先 g = gcd(den, b) 再乘，中间结果更小。2017③ 的分数序列到第 20 项，精确分母有 28 位——long long 装不下，所以原题用 double 是对的。

随机数（学长清单「随机数输入」）：#include <stdlib.h>、#include <time.h>，程序开头调用一次 srand(time(NULL));，之后 rand() % (b - a + 1) + a 得到 [a, b] 之间的随机整数。srand 写在循环里，每次都用同一个种子，得到的数全一样。

等差、等比数列：能用公式就用公式（等差 n(a1 + an)/2），但等比 q^n 用 pow 得到 double，要整数结果就用循环乘，并留意溢出。
